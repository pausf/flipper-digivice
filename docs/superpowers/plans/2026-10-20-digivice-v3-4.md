# Digivice v3.4 (turn-based duel) Design and Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax. One fresh, short-lived agent per task (usage budget is nearly exhausted): a task must be doable from this document and the files it names. Sonnet is enough for every task.

**Goal:** Replace the v3.1 battle (charge gauge, high/low aim, first to 3 hits) with a Pokemon-style turn-based duel: HP bars with numbers on both sides, a LUCHAR / OBJETO / HUIR menu, four moves per fighter with PP and attribute icons, speed order, damage with the attribute triangle, STAB and critical hits, foe AI. Every outcome and integration of v3.3 (results, rewards, injury, corruption, Shield, boss gates, streaks, partners and capture, VIRUX, counters, the encounter lead-in) stays.

**Architecture:** Two new pure-C modules, host-tested first: `digivice_moves.c` (the move table and the stage+attribute assignment rule) and `digivice_duel.c` (fighter stats, damage, foe AI, the turn state machine, `digivice_duel_init` from an encounter). A fighter is built from the single power number P the v3.1 code already computes (pet: stage power + strength, x3/4 injured; foes: area power, boss, city, partner, VIRUX), so no foe table changes. The old gauge/aim/hit-count rules in `digivice_battle.c` stay compiling until Task 4 swaps the UI, then go; the timing bar survives as the optional skill bonus (critical hit). `digivice_rules_battle_result` and the whole service are untouched: **no save-format change** (still v5, 148 B).

**Tech Stack:** C11, Flipper Zero firmware (furi, gui/canvas, notification), u8g2 `u8g2_font_4x6_tf`, host `cc` for tests, GitHub Actions (`fbt`) on the private remote `digivice`.

**Inputs:** previous plan `docs/superpowers/plans/2026-10-20-digivice-v3-3.md` (conventions, copied below); mockup `docs/superpowers/mockups/v3/v3-combate.html` (attribute shots, hit flash, shake, hop; its arena layout is replaced here); code under `applications/services/digivice/` (`digivice_battle.*`, `digivice_rules.h`, `digivice_roster.*`, `digivice_homage.*`, `digivice_city.*`, `digivice_expedition.*`, `digivice_i18n.*`) and `applications/main/digivice/digivice_app_battle.c`, `digivice_app_i.h`.

**Mapping to the requested T1 to T5:** T1 Task 1; T2 Task 2; T3 Task 3; T4 Task 4; T5 Task 5. Plan against current code of `digivice-v3.3`; if its final review lands fixes in `digivice_battle.*`, `digivice_app_battle.c` or `digivice_i18n.*`, re-read them before Tasks 3 and 4.

# Part 1: Spec

## Scope

In: the duel rules, 26 original moves, four moves per fighter, the new battle UI, new strings. Out: persistent HP or PP, new items, switching pets, link battles, any change to evolution, rewards or the save.

## Rules (every number lives in `digivice_config.h`)

**Fighter from power P.** `level = 20 + P/6`, `hp = hp_max = 2*level + 10`, `atk = def = 100 + P`, `spd = 10 + P/2 + 2*vigor` (pet only), `shot` = the v3.1 projectile size. P=40 (Champion, no strength): level 26, HP 62, ATK/DEF 140, SPD 30. P=0 gives level 20, HP 50. Pet P: `digivice_rules_player_power` (stage power + strength up to 24, x3/4 while injured, so injury still hurts). Foe P: trail foe, boss and city monster use the v3.1 value x `DIGIVICE_FOE_POWER_PCT` (85, a tuning knob because turn-based fights are far less random than v3.1's hit rolls); partner = pet stage power x1.2 (unscaled); VIRUX = v3.1 table (unscaled).

**Turn.** Each round: the pet picks LUCHAR (a move), OBJETO (the Shield) or HUIR; the foe picks by AI at the same time; priority (+1 for RAFAGA) then SPD (halved while glitched; the pet wins ties) decides who acts first; the second acts only if both still stand; a round ends with `round++`. After `DIGIVICE_TURN_CAP` (20) rounds the higher HP fraction wins, an exact tie is a Draw (the foe flees, as before). KO is Win or Lose. HUIR is Fled and always works where the v3.1 retreat did (`digivice_battle_retreat_allowed`); streak areas answer the existing "NO HAY ESCAPE" notice.

**Damage** (all integer): `((2*L/5 + 2) * power * atk' / def' / 50) + 2`, where atk'/def' apply the lowered steps (x0.80 one step, x0.64 two, `DIGIVICE_STAGE_X100`); then x1.5 super effective / x0.67 not very (move attribute vs defender attribute, Nulo neutral; Portador > Ruido > Cifrado > Portador); x1.2 STAB when the move attribute equals the user's; x1.5 critical; x(85 + 16*var/100)/100 for var 0..99; at least 1. Charge (x2, once) and guard (/2 rounded up, once) apply in `digivice_duel_act`. Critical: 1 in 16, or guaranteed by the timing bar.

**Accuracy and effects.** A move hits when `roll < acc` (acc 0 = never checked). A damaging move's side effect lands when `roll < arg`; status moves apply at once. Effects: ATK down, DEF down (target, max two steps), heal (`arg`% of max HP), charge (SOBRECARGA: next damaging move x2), glitch (target loses 25% of its turns without spending PP and has half SPD; lasts the duel), shield (ESCUDO DATOS: halves the next damage), quick (priority +1). Corruption >= 50 (`glitchy`): 25% of the pet's moves fail (`DIGIVICE_CORRUPTION_MISS_PCT`, as before). Every PP spent: all four at 0 means the move is LUCHA (power 35, always usable).

**Moves** (name, power/acc/PP, attribute; ASCII, never translated; Spanish uppercase technique names). Basic: ZARPAZO 40/100/25, MORDISCO 50/95/20, EMBESTIDA 70/90/15 (Nulo). Utility: REPARAR heal 50% /8, ESCUDO DATOS (Cifrado) /8, SOBRECARGA /5, RAFAGA 30/100/20 quick, GRITO (ATK down 100%) /15, FRAGMENTAR (DEF down 100%) /15, LUCHA. Per attribute (mid 55, heavy 85-90, two with a side effect): Portador ONDA CHOQUE, TSUNAMI, OLA BAJA (DEF down 30%), RESACA (ATK down 30%); Ruido PIXEL BEAM, TORMENTA, RAYO GLITCH (glitch 30%), INTERFERIR (ATK down 30%); Cifrado CIFRAR, HACKEO, CLAVE ROTA (DEF down 40%), BLOQUEO (glitch 25%); Nulo ONDA NULA, PULSO FINAL, CHISPAZO (glitch 20%), FRENAZO (DEF down 30%). Exact numbers are the table in Task 2.

**Assignment, no per-form table.** `digivice_moves_assign(tier, attr, seed, force_util)`: tier 0 Baby/Baby II, 1 Rookie, 2 Champion, 3 Ultimate, 4 Mega (`digivice_duel_tier`). Slot 0: ZARPAZO (tier 0), MORDISCO (1-2), EMBESTIDA (3-4). Slot 1: the attribute's mid move (heavy from tier 3). Slot 2: effect A or B by `seed & 1`. Slot 3: utility `{REPARAR, ESCUDO DATOS, SOBRECARGA, RAFAGA, GRITO, FRAGMENTAR}[(seed + tier) % 6]`. Seed: pet form id, trail foe id, city monster index, partner id, boss area, VIRUX type. Overrides: bosses tier `2 + area/3` and slot 3 SOBRECARGA (odd area) or ESCUDO DATOS (even); VIRUX slot 3 SOBRECARGA; city monsters tier 2; trail foes tier 2 (champion) or 1; partners and VIRUX use the pet's tier. The data cost is one 16-entry kit, a 6-entry utility list and the table: no per-form array.

**Foe AI** (`digivice_fighter_pick`): weight per move with PP: damaging `10 + power/4`, x2 super effective, /2 not very, +20% STAB; heal 120 only below 35% HP; shield 12 and charge 14 when not already up; ATK/DEF down 12 while not at two steps; weighted random on a 0..255 roll; nothing worth it or no PP: LUCHA.

**Messages** (Spanish; English in Task 4): `<NOMBRE> USO` / `<MOVE>!`; then in order critical `!GOLPE CRITICO!`, `!ES MUY EFICAZ!` or `NO ES MUY EFICAZ...`, then the effect line (`!ATAQUE BAJA!`, `!DEFENSA BAJA!`, `!RECUPERA SALUD!`, `!ACUMULA ENERGIA!`, `!SE PROTEGE!`, `!QUEDA EN GLITCH!`); `!FALLO!` on a miss; `!EL GLITCH LO FRENA!` on a lost turn; `!EL ESCUDO AGUANTA!` when the item cancels a hit (accents and inverted marks as in i18n).

**Item.** OBJETO lists the held Shield. Using it costs the turn (the foe still acts) and arms it: the next damaging foe hit is cancelled and the Shield is consumed only then (`shield_used`); an armed Shield that never met a hit is kept, as in v3.1. This replaces the old passive Shield: an intended trade (the foe's first hit is no longer free).

**Timing bar (skill bonus).** After choosing a damaging move the v3.1 meter runs (same zone width from strength, 30 frames, OK locks). OK inside the zone = the hit is a guaranteed critical; anywhere else nothing changes (no penalty). Status moves skip the bar.

**Persistence: none.** HP and PP exist only inside one duel and start full, so PP "restores after each battle" for free and the save stays v5, 148 B. A persistent HP would need rest rules in the care loop and a v6 migration for a feature nobody asked for; injury already carries the cost of a lost fight across duels (x3/4 power, so lower level, HP and ATK).

**Preserved untouched:** `digivice_rules_battle_result` (rewards, Baby exemption for corruption, injury, streak and boss rules, partner capture and `special_count`, VIRUX data), counters for evolution, `digivice_battle_retreat_allowed`, boss gates, the encounter lead-in (its "POW n" line becomes "LV n"), the End screen and the capture reveal.

## Decisions

| # | Decision | Why |
|---|---|---|
| D1 | One input number P per fighter. | Reuses every v3.1 foe and area table; zero new foe data. |
| D2 | Moves by rule (tier, attribute, seed), not per form. | 4 slots for ~60 combatants cost 26 table rows, not 240. |
| D3 | Move attribute drives the triangle, user attribute drives STAB. | Pet attribute = its kit, so STAB is the norm; the triangle is the matchup. |
| D4 | No HP/PP persistence, no state bump. | Save stays v5; PP restore is free. |
| D5 | The timing bar becomes the critical bonus, never a penalty. | Keeps the skill element without making every turn a minigame chore. |
| D6 | OBJETO costs the turn and arms the Shield. | Pokemon-like item economy; the Shield stays a one-hit item. |
| D7 | `DigiviceDuel` is a new type; the old `DigiviceBattle` dies in Task 4. | Tasks 2 and 3 compile beside the old UI. |
| D8 | End screen and capture reveal keep the v3.3 full-screen layout. | Zero risk to capture; the cut from the duel arena to the result screen is a scene change. |
| D9 | `DIGIVICE_FOE_POWER_PCT` 85. | Host AI-vs-AI sims: a 10% power gap already moves the win rate 50% to about 20%; tune on the device. |
| D10 | Flash ceiling for v3.4: at most **+15,360 bytes (15 KB) of `text + data`** over the v3.3 build. | Checkpoints: Task 2 +2 KB, Task 3 +5 KB, Task 4 +10 KB. |

## Global Constraints (from v3.3, unchanged unless stated)

- New branch `digivice-v3.4` from the head of `digivice-v3.3` (Task 1). Never commit to `main` or an earlier `digivice-*` branch. Executors run only `applications/services/digivice/test/run.sh` and never push; the controller pushes (Task 5).
- Tools: `rg`, `fd`, `bat`, `eza`, `sd` only (never `grep`, `find`, `cat`, `ls`, `sed`); never `sd` with `$` in the replacement.
- Every tuning number lives in `digivice_config.h`. `digivice_moves.*`, `digivice_duel.*`, `digivice_battle.*`, `digivice_rules.*`, `digivice_roster.*`, `digivice_i18n.*` stay pure C (no furi includes), written test-first, host-tested (`cc -std=c11 -Wall -Wextra -Werror`); partner tests wrapped in `#if DIGIVICE_EASTER_EGGS`; `run.sh` runs the suites again with `-DDIGIVICE_EASTER_EGGS=0` (both flag values must compile).

- fbt flags `-Wall -Wextra -Werror -Wstrict-prototypes -Wredundant-decls -Wdouble-promotion -Wundef` plus `-Wformat-truncation` and `-Wswitch`: size every `snprintf` for the worst case (u32 10 digits, u16 5, u8 3, `%s` at full UTF-8 length); add each new enum value to every `switch`; an unused non-`inline` static function is an error; every file testing `DIGIVICE_EASTER_EGGS` includes `digivice_config.h` first. - u8g2 coordinates are unsigned: never pass a negative x or y to raw `canvas_draw_*`; use the clipped `digivice_draw_*` helpers or keep coordinates on screen.
- Conventional Commits, **no `Co-Authored-By` and no AI attribution anywhere** (overrides any default). Stage explicit paths only (`git add <path>...`, never `.` or `-A`). Untracked files elsewhere (for example `web/graphql.stg`-style secrets) stay untouched.
- Repo style: 4-space indent, `if(` `for(` `while(` `switch(` without a space, 99 columns, comments only on non-obvious code at the neighbours' density, `ponytail:` comments in English.
- The service lists its sources in `applications/services/digivice/application.fam`: every new `.c` is added in the task that creates it. The app folder is globbed. Service stack stays 3K (the duel adds no large locals: `DigiviceDuel` lives in the app).
- Stock-file diff limited to digivice files, `applications/services/digivice/test/run.sh` and the workflow. No official sprite or trademarked art; v3.4 adds none.
- Flash ceiling: +15,360 bytes of `text + data` over the v3.3 baseline (Task 1 records it from the latest green `digivice-v3.3` CI run). If a push is more than 1.5 KB over its checkpoint, stop and cut: first the dither/zzz-style extras in the HUD, then the English wording of the effect lines, then the OBJETO pseudo-step animation; above the ceiling after all cuts: re-scope.

// Host-side test for the move table. Run: applications/services/digivice/test/run.sh
#include "../digivice_config.h"
#include "../digivice_moves.h"

#include <stdio.h>
#include <string.h>

static int failures = 0;

#define CHECK(cond)                                                \
    do {                                                           \
        if(!(cond)) {                                              \
            printf("FAIL %s:%d: %s\n", __FILE__, __LINE__, #cond); \
            failures++;                                            \
        }                                                          \
    } while(0)

static void test_table(void) {
    CHECK(DigiviceMoveCount == 26);
    for(uint8_t id = 0; id < DigiviceMoveCount; id++) {
        const DigiviceMove* m = digivice_move(id);
        size_t len = strlen(m->name);
        CHECK(len >= 4 && len <= 12);
        for(size_t i = 0; i < len; i++) {
            CHECK(m->name[i] == ' ' || (m->name[i] >= 'A' && m->name[i] <= 'Z'));
        }
        CHECK(m->power <= 100 && m->acc <= 100);
        CHECK(m->attr < DigiviceAttrCount && m->fx < DigiviceFxCount);
        CHECK(id == DigiviceMoveLucha || m->pp >= 5);
        CHECK(m->power > 0 || m->fx != DigiviceFxNone);
        for(uint8_t j = 0; j < id; j++) CHECK(strcmp(digivice_move(j)->name, m->name) != 0);
    }
    CHECK(strcmp(digivice_move(200)->name, "LUCHA") == 0);
    // Kit layout: mid, heavy, effect A, effect B of the attribute.
    for(uint8_t attr = 0; attr < DigiviceAttrCount; attr++) {
        for(uint8_t k = 0; k < 4; k++) {
            const DigiviceMove* m = digivice_move((uint8_t)(DigiviceMoveKit + attr * 4 + k));
            CHECK(m->attr == attr && m->power > 0);
            CHECK((k < 2) == (m->fx == DigiviceFxNone));
        }
    }
}

static void test_assign(void) {
    uint8_t out[4];
    digivice_moves_assign(0, DigiviceAttrNulo, 0, DIGIVICE_MOVE_NONE, out);
    CHECK(out[0] == DigiviceMoveZarpazo && out[3] == DigiviceMoveReparar);
    CHECK(strcmp(digivice_move(out[1])->name, "ONDA NULA") == 0);
    CHECK(strcmp(digivice_move(out[2])->name, "CHISPAZO") == 0);
    digivice_moves_assign(1, DigiviceAttrCifrado, 1, DIGIVICE_MOVE_NONE, out);
    CHECK(out[0] == DigiviceMoveMordisco && out[3] == DigiviceMoveSobrecarga); // (1 + 1) % 6
    CHECK(strcmp(digivice_move(out[2])->name, "BLOQUEO") == 0); // odd seed: effect B
    digivice_moves_assign(4, DigiviceAttrRuido, 3, DIGIVICE_MOVE_NONE, out);
    CHECK(out[0] == DigiviceMoveEmbestida && out[3] == DigiviceMoveEscudoDatos);
    CHECK(strcmp(digivice_move(out[1])->name, "TORMENTA") == 0);
    digivice_moves_assign(2, DigiviceAttrPortador, 0, DigiviceMoveSobrecarga, out);
    CHECK(out[3] == DigiviceMoveSobrecarga);
    // Every tier, attribute and seed gets three damaging moves and never LUCHA.
    for(uint8_t tier = 0; tier <= 5; tier++) {
        for(uint8_t attr = 0; attr <= DigiviceAttrCount; attr++) {
            for(uint16_t seed = 0; seed < 64; seed++) {
                digivice_moves_assign(tier, attr, (uint8_t)seed, DIGIVICE_MOVE_NONE, out);
                uint8_t damaging = 0;
                for(int i = 0; i < 4; i++) {
                    CHECK(out[i] < DigiviceMoveCount && out[i] != DigiviceMoveLucha);
                    damaging += digivice_move(out[i])->power > 0;
                }
                CHECK(damaging >= 3);
            }
        }
    }
}

int main(void) {
    test_table();
    test_assign();
    if(failures) {
        printf("%d failure(s)\n", failures);
        return 1;
    }
    printf("digivice moves: all passed\n");
    return 0;
}

`test/digivice_duel_test.c` (Task 3 appends to it)

```c
// Host-side test for the duel rules. Run: applications/services/digivice/test/run.sh
#include "../digivice_city.h"
#include "../digivice_config.h"
#include "../digivice_duel.h"

#include <stdio.h>
#include <string.h>

static int failures = 0;

#define CHECK(cond)                                                \
    do {                                                           \
        if(!(cond)) {                                              \
            printf("FAIL %s:%d: %s\n", __FILE__, __LINE__, #cond); \
            failures++;                                            \
        }                                                          \
    } while(0)

#define T0 (10UL * 86400UL + 8UL * 3600UL) // day 10 at 08:00

// A Champion-tier fighter of power `power`, shot size 5, plain moves.
static DigiviceFighter fighter(uint16_t power, uint8_t attr) {
    DigiviceFighter f;
    DigiviceFighterSpec spec = {
        .power = power, .attr = attr, .tier = 2, .force_util = DIGIVICE_MOVE_NONE, .shot = 5};
    digivice_fighter_init(&f, &spec);
    return f;
}

static void set_moves(DigiviceFighter* f, uint8_t a, uint8_t b, uint8_t c, uint8_t e) {
    f->moves[0] = a;
    f->moves[1] = b;
    f->moves[2] = c;
    f->moves[3] = e;
    for(int i = 0; i < DIGIVICE_SLOTS; i++) f->pp[i] = digivice_move(f->moves[i])->pp;
}

static void test_tier_and_stats(void) {
    CHECK(digivice_duel_tier(DigiviceStageBaby2) == 0);
    CHECK(digivice_duel_tier(DigiviceStageRookie) == 1);
    CHECK(digivice_duel_tier(DigiviceStageMega) == 4);
    DigiviceFighter f = fighter(40, DigiviceAttrRuido);
    CHECK(f.level == 26 && f.hp == 62 && f.hp_max == 62);
    CHECK(f.atk == 140 && f.def == 140 && f.spd == 30 && f.shot == 5);
    CHECK(f.pp[0] == digivice_move(f.moves[0])->pp);
    f = fighter(131, DigiviceAttrNulo); // an area 8 boss at full power
    CHECK(f.level == 41 && f.hp_max == 92 && f.atk == 231);
    DigiviceFighterSpec spec = {
        .power = 64, .attr = DigiviceAttrNulo, .force_util = DIGIVICE_MOVE_NONE, .spd_bonus = 4};
    digivice_fighter_init(&f, &spec);
    CHECK(f.spd == 10 + 32 + 4);
}

static void test_damage(void) {
    // Level 26, ATK 140 against DEF 140: (2 * 26 / 5 + 2) * 55 * 140 / 140 / 50 + 2 = 15.
    DigiviceFighter a = fighter(40, DigiviceAttrCifrado);
    DigiviceFighter d = fighter(40, DigiviceAttrNulo);
    const DigiviceMove* neutral = digivice_move(DigiviceMoveKit + 12); // ONDA NULA, Nulo 55
    const DigiviceMove* wave = digivice_move(DigiviceMoveKit + 0); // ONDA CHOQUE, Portador 55
    CHECK(digivice_duel_damage(&a, &d, neutral, false, 99) == 15);
    CHECK(digivice_duel_damage(&a, &d, neutral, false, 0) == 12); // the 85% roll
    CHECK(digivice_duel_damage(&a, &d, neutral, true, 99) == 22); // critical x1.5
    // Triangle: Portador beats Ruido (x1.5) and loses to Cifrado (x0.67).
    d.attr = DigiviceAttrRuido;
    CHECK(digivice_duel_damage(&a, &d, wave, false, 99) == 22);
    d.attr = DigiviceAttrCifrado;
    CHECK(digivice_duel_damage(&a, &d, wave, false, 99) == 10);
    d.attr = DigiviceAttrNulo;
    a.attr = DigiviceAttrPortador; // STAB x1.2
    CHECK(digivice_duel_damage(&a, &d, wave, false, 99) == 18);
    // One lowered ATK step is x0.80; two lowered DEF steps divide by x0.64.
    a.attr = DigiviceAttrCifrado;
    a.atk_low = 1;
    CHECK(digivice_duel_damage(&a, &d, neutral, false, 99) == 12);

#include "digivice_config.h"

#include <string.h>

static const uint8_t stage_x100[DIGIVICE_STAGE_MAX + 1] = DIGIVICE_STAGE_X100;

uint8_t digivice_duel_tier(DigiviceStage stage) {
    return stage <= DigiviceStageBaby2 ? 0 : (uint8_t)(stage - DigiviceStageBaby2);
}

void digivice_fighter_init(DigiviceFighter* f, const DigiviceFighterSpec* spec) {
    memset(f, 0, sizeof(DigiviceFighter));
    f->level = (uint8_t)(DIGIVICE_LEVEL_BASE + spec->power / DIGIVICE_LEVEL_DIV);
    f->hp_max = (uint16_t)(DIGIVICE_HP_MULT * f->level + DIGIVICE_HP_BASE);
    f->hp = f->hp_max;
    f->atk = (uint16_t)(DIGIVICE_STAT_BASE + spec->power);
    f->def = f->atk;
    f->spd = (uint16_t)(DIGIVICE_SPD_BASE + spec->power / 2 + spec->spd_bonus);
    f->attr = spec->attr;
    f->shot = spec->shot;
    digivice_moves_assign(spec->tier, spec->attr, spec->seed, spec->force_util, f->moves);
    for(uint8_t i = 0; i < DIGIVICE_SLOTS; i++) f->pp[i] = digivice_move(f->moves[i])->pp;
}

uint16_t digivice_duel_damage(
    const DigiviceFighter* attacker,
    const DigiviceFighter* defender,
    const DigiviceMove* move,
    bool crit,
    uint8_t var) {
    uint32_t atk = (uint32_t)attacker->atk * stage_x100[attacker->atk_low] / 100;
    uint32_t def = (uint32_t)defender->def * stage_x100[defender->def_low] / 100;
    if(def == 0) def = 1;
    uint32_t dmg = (2U * attacker->level / 5 + 2) * move->power * atk / def / 50 + 2;
    int8_t edge = digivice_rules_attr_adv(move->attr, defender->attr);
    if(edge > 0) {
        dmg = dmg * DIGIVICE_ADV_X100 / 100;
    } else if(edge < 0) {
        dmg = dmg * DIGIVICE_DIS_X100 / 100;
    }
    if(move->attr == attacker->attr) dmg = dmg * DIGIVICE_STAB_X100 / 100;
    if(crit) dmg = dmg * DIGIVICE_CRIT_X100 / 100;
    dmg = dmg * (DIGIVICE_ROLL_MIN + var * (100 - DIGIVICE_ROLL_MIN + 1) / 100) / 100;
    return (uint16_t)(dmg ? dmg : 1);
}

static uint16_t pick_weight(
    const DigiviceFighter* me,
    const DigiviceFighter* foe,
    const DigiviceMove* m) {
    if(m->power) {
        uint16_t w = DIGIVICE_AI_ATTACK_BASE + m->power / 4;
        int8_t edge = digivice_rules_attr_adv(m->attr, foe->attr);
        if(edge > 0) {
            w *= 2;
        } else if(edge < 0) {
            w /= 2;
        }
        if(m->attr == me->attr) w += w / 5;
        return w ? w : 1;
    }
    switch(m->fx) {
    case DigiviceFxHeal: {
        bool low = (uint32_t)me->hp * 100 < (uint32_t)me->hp_max * DIGIVICE_HEAL_LOW_PCT;
        return low && me->hp < me->hp_max ? 120 : 0;
    }
    case DigiviceFxShield:
        return me->guard ? 0 : 12;
    case DigiviceFxCharge:
        return me->charged ? 0 : 14;
    case DigiviceFxAtkDown:
        return foe->atk_low < DIGIVICE_STAGE_MAX ? 12 : 0;
    case DigiviceFxDefDown:
        return foe->def_low < DIGIVICE_STAGE_MAX ? 12 : 0;
    default:
        return 0;
    }
}

bool digivice_fighter_spent(const DigiviceFighter* f) {
    for(uint8_t i = 0; i < DIGIVICE_SLOTS; i++) {
        if(f->pp[i]) return false;
    }
    return true;
}

uint8_t digivice_fighter_pick(
    const DigiviceFighter* me,
    const DigiviceFighter* foe,
    uint8_t roll) {
    uint16_t w[DIGIVICE_SLOTS];
    uint32_t sum = 0;
    for(uint8_t i = 0; i < DIGIVICE_SLOTS; i++) {
        w[i] = me->pp[i] ? pick_weight(me, foe, digivice_move(me->moves[i])) : 0;
        sum += w[i];
    }
    if(sum == 0) return DIGIVICE_SLOT_STRUGGLE;
    uint32_t target = (uint32_t)roll * sum / 256;
    for(uint8_t i = 0; i < DIGIVICE_SLOTS; i++) {
        if(target < w[i]) return i;
        target -= w[i];
    }
    return DIGIVICE_SLOT_STRUGGLE;
}

// Both sides play the foe AI with random dice; the duel must end within the round cap.
static DigiviceBattleOutcome play_out(DigiviceDuel* d, uint32_t* seed) {
    while(digivice_duel_outcome(d) == DigiviceBattleOngoing) {
        uint8_t ps = digivice_fighter_pick(&d->f[0], &d->f[1], (uint8_t)lcg(seed));
        uint8_t fs = digivice_fighter_pick(&d->f[1], &d->f[0], (uint8_t)lcg(seed));
        bool pfirst = digivice_duel_player_first(d, ps, fs);
        for(int turn = 0; turn < 2; turn++) {
            bool player = (turn == 0) == pfirst;
            DigiviceRolls r = {
                .acc = (uint8_t)(lcg(seed) % 100),
                .var = (uint8_t)(lcg(seed) % 100),
                .crit = (uint8_t)(lcg(seed) % 256),
                .fx = (uint8_t)(lcg(seed) % 100),
                .para = (uint8_t)(lcg(seed) % 100),
                .miss = (uint8_t)(lcg(seed) % 100),
            };
            act(d, player ? DigiviceSidePlayer : DigiviceSideFoe, player ? ps : fs, &r);
            if(d->f[0].hp == 0 || d->f[1].hp == 0) break;
        }
        digivice_duel_end_round(d);
        if(d->round > DIGIVICE_TURN_CAP) return DigiviceBattleOngoing;
    }
    return digivice_duel_outcome(d);
}

static int win_percent(uint16_t p, uint8_t pa, uint16_t q, uint8_t qa) {

    const DigiviceRolls* rolls) {
    DigiviceFighter* me = &d->f[actor];
    DigiviceFighter* you = &d->f[1 - actor];
    DigiviceStep step = {.actor = actor, .slot = slot, .result = DigiviceStepDone};

    if(me->glitch && rolls->para < DIGIVICE_GLITCH_SKIP_PCT) {
        step.result = DigiviceStepSkipped;
        return step;
    }
    if(slot >= DIGIVICE_SLOTS || me->pp[slot] == 0) slot = DIGIVICE_SLOT_STRUGGLE;
    step.slot = slot;
    step.move = slot < DIGIVICE_SLOTS ? me->moves[slot] : DigiviceMoveLucha;
    if(slot < DIGIVICE_SLOTS) me->pp[slot]--;
    const DigiviceMove* m = digivice_move(step.move);

    bool corrupt_fail = actor == DigiviceSidePlayer && d->glitchy &&
                        rolls->miss < DIGIVICE_CORRUPTION_MISS_PCT;
    if(corrupt_fail || (m->acc && rolls->acc >= m->acc)) {
        step.result = DigiviceStepMissed;
        return step;
    }

    if(m->power) {
        if(actor == DigiviceSideFoe && d->shield_armed) {
            d->shield_armed = false;
            d->shield_used = true;
            step.result = DigiviceStepShielded;
            return step;
        }
        step.crit = crit_bonus || rolls->crit % DIGIVICE_CRIT_ODDS == 0;
        step.edge = digivice_rules_attr_adv(m->attr, you->attr);
        uint32_t dmg = digivice_duel_damage(me, you, m, step.crit, rolls->var);
        if(me->charged) {
            dmg *= DIGIVICE_CHARGE_X;
            me->charged = false;
        }
        if(you->guard) {
            dmg = (dmg + 1) / 2;
            you->guard = false;
        }
        if(dmg > you->hp) dmg = you->hp;
        you->hp = (uint16_t)(you->hp - dmg);
        step.damage = (uint16_t)dmg;
        if(rolls->fx < m->arg && apply_fx(you, m->fx)) step.fx = m->fx;
        return step;
    }

    switch(m->fx) {
    case DigiviceFxHeal: {
        uint32_t amount = (uint32_t)me->hp_max * m->arg / 100;
        if(amount > (uint32_t)(me->hp_max - me->hp)) amount = (uint32_t)(me->hp_max - me->hp);
        me->hp = (uint16_t)(me->hp + amount);
        step.healed = (uint16_t)amount;
        step.fx = DigiviceFxHeal;
        break;
    }
    case DigiviceFxShield:
        me->guard = true;
        step.fx = DigiviceFxShield;
        break;
    case DigiviceFxCharge:
        me->charged = true;
        step.fx = DigiviceFxCharge;
        break;
    default:
        if(apply_fx(you, m->fx)) step.fx = m->fx;
        break;
    }
    return step;
}

void digivice_duel_end_round(DigiviceDuel* d) {
    if(d->round < UINT8_MAX) d->round++;
}

DigiviceBattleOutcome digivice_duel_outcome(const DigiviceDuel* d) {
    const DigiviceFighter* p = &d->f[DigiviceSidePlayer];
    const DigiviceFighter* q = &d->f[DigiviceSideFoe];
    if(q->hp == 0) return DigiviceBattleWon;
    if(p->hp == 0) return DigiviceBattleLost;
    if(d->round < DIGIVICE_TURN_CAP) return DigiviceBattleOngoing;
    uint32_t mine = (uint32_t)p->hp * q->hp_max;
    uint32_t theirs = (uint32_t)q->hp * p->hp_max;
    if(mine > theirs) return DigiviceBattleWon;
    if(theirs > mine) return DigiviceBattleLost;
    return DigiviceBattleDrawn;
}
```
