# Digivice v2.1 (base and care) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the v1 digivice into a store-bought style V-Pet: Spanish/English UI, Normal/Hacker modes, poop, light, sickness and medicine, a 5-minute hatch, and an icon main screen with Feed, Clean, Light, Cure, Profile and Settings screens, without losing the pet already on the device.

**Architecture:** All game rules stay in the pure-C `digivice_rules.c` (host-tested). The tick now walks wall time in hour segments that are fully awake or fully asleep and, inside each segment, steps from event to event, so 60 s ticks and one long catch-up tick end in the same state. A new pure-C `digivice_i18n.c` holds every user-visible string in two tables. The service gains a v1->v2 save migration and a small care API; the draw kit gains the mockup bitmaps and night effects; the app replaces its text menu with the 8-icon screen.

**Tech Stack:** C11, Flipper Zero firmware (furi, gui/canvas, notification, saved_struct), u8g2 `u8g2_font_4x6_tf`, host `cc` for tests, GitHub Actions (`fbt`) on the private remote `digivice`.

**Spec (source of truth):** `docs/superpowers/specs/2026-10-14-digivice-v2-1-base-care-design.md`. Mockups: `.superpowers/brainstorm/12173-1791968437/content/v2-classic.html` and `v2-designs.html`.

## Global Constraints

- All work happens on a new branch `digivice-v2.1` created from `main` (Task 1). Never commit to `main`.
- Never run `./fbt` locally. CI (`.github/workflows/digivice.yml` on remote `digivice` = `pausf/flipper-digivice`) runs the host tests and `./fbt COMPACT=1 DEBUG=0 updater_package` on every push. The controller pushes and watches CI; a task executor never pushes.
- Every tuning number lives in `applications/services/digivice/digivice_config.h`.
- `digivice_rules.c/.h`, `digivice_i18n.c/.h` and `digivice_config.h` stay pure C with no furi includes. They are host-tested by `applications/services/digivice/test/run.sh` (`cc -std=c11 -Wall -Wextra -Werror`, binaries written to `$TMPDIR`).
- Source files are ASCII-only. Spanish accents live only in `digivice_i18n.c`, written as escapes (see decision D1: they are UTF-8 escapes, not Latin-1). The i18n host test scans every digivice source for non-ASCII bytes.
- fbt builds with `-Werror`, including `-Wformat-truncation`. Size every `snprintf` buffer for the worst case: u32 = 10 digits, u16 = 5, u8 = 3, and every `%s` at its full UTF-8 byte length (2 bytes per accented glyph). Prefer small integer types gcc can bound.
- Conventional Commits. No `Co-Authored-By` lines and no AI attribution anywhere. Stage explicit paths only (`git add <path>...`); never `git add .` or `git add -A`.
- Repo style: 4-space indent, `if(` / `for(` / `while(` / `switch(` with no space, column limit 99, comments only on non-obvious code, matching the neighbours' comment density.
- Keep v1 behaviour wherever the spec does not change it: feeding, battle maths, corruption, evolution thresholds, the home layout, the cutscene.
- Save format: magic `0xD1`, version `0x02`. `DigiviceStateV1` is a frozen copy of the v1 layout and must never change.
- Device checks use the CI artifact `digivice-update-package` of the pushed commit, flashed with qFlipper. Only flash after CI is green.

## Decisions taken while planning (spec ambiguities)

- **D1. Accents are UTF-8 escapes.** The spec says `canvas_draw_str` passes bytes straight to u8g2, but `applications/services/gui/canvas.c:183`, `:226` and `:232` call `u8g2_DrawUTF8` / `u8g2_GetUTF8Width`. Its decoder (`lib/u8g2/u8x8_8x8.c:276`) treats any byte >= 0xC0 as a UTF-8 lead byte, so a raw Latin-1 `"\xC1"` (Á) would swallow the next letter. Strings therefore use UTF-8 escapes (`"\xC3\x81"` for Á), which decode to the Latin-1 code points that `u8g2_font_4x6_tf` holds. `digivice_i18n_text_width` counts UTF-8 lead bytes. The source stays ASCII-only, as the spec requires.
- **D2. Tick accounting.** Wall time from `last_tick` (clamped to 48 h, as v1) is split at clock-hour boundaries into segments that are entirely awake or asleep. Awake segments step event by event over hunger, mood, corruption hours and poop accrual (all paused while asleep, as v1 pauses hunger and mood). Wall-clock rules run in both kinds of segment: the 6 h dirty-poop mistake, the 24 h starvation sickness (`starving_since` is a wall timestamp) and the light-on-while-asleep hour. `test_60s_ticks_match_one_tick_with_care` proves 60 s ticks and one 30 h tick produce byte-identical states.
- **D3. Faster mood decay** is x2 when sick OR when poop >= 3. The two do not stack.
- **D4. Second dose:** fires once, when a tick window `(old last_tick, now]` crosses `sick_since + 12 h` while `doses_needed == 1`. No extra state field is needed.
- **D5. A full cure while still starving** restarts `starving_since` at the cure time. Without this the pet would relapse on the next tick.
- **D6. An Egg has no care mistakes:** it never poops (spec), and the light rule skips it too. This keeps v1's `test_sleep_window` (an egg sleeping with the light on keeps full mood).
- **D7. Light:** `light_on` returns to 1 and `light_on_asleep_s` to 0 at the start of every awake segment (the 07:00 reset). `toggle_light` refuses whenever awake, with the notice "ESTÁ DESPIERTO" / "IT'S AWAKE" (the spec gives no text).
- **D8. Refusals:** training is refused when sick (checked first) or asleep; battling only when sick (spec); feeding is unchanged from v1. Curing a healthy pet shows "ESTÁ SANO".
- **D9. Notifications:** getting sick gives a red blink plus a short buzz, or only the red blink in the sleep window. A new poop gives one green blink. Poop only accrues while awake, so it never fires at night.
- **D10.** The service calls `digivice_rules_evolve` right after training, because training EXP can now cross the Rookie threshold.
- **D11. Main screen:** moving the cursor shows the icon's name in the notice box for 1.5 s, so every icon explains itself. Refusals use the same box.
- **D12. FICHA layout:** the mode sits in the header, the type and FALLOS ("ERRORS") under the portrait, and data per type only in Hacker mode. The FUERZA bar is full at `DIGIVICE_STRENGTH_BAR_MAX = 24`. The EXP bar shows progress toward the next evolution.
- **D13. AJUSTES:** ↑/↓ choose a row; OK or ←/→ change it; Back leaves. "Reiniciar bicho" needs OK on "¿SEGURO?" and then OK on "¿DE VERDAD?". Any other key cancels. A reset returns to the main screen with "¡NUEVO HUEVO!".
- **D14. CI trigger:** the workflow only ran on pushes to `main`. Task 1 adds `digivice-*` so the branch builds.
- **D15. Load:** the service checks magic, version and payload size from `saved_struct_get_metadata` (`lib/toolbox/saved_struct.h:56`: `bool saved_struct_get_metadata(const char* path, uint8_t* magic, uint8_t* version, size_t* payload_size)`) before loading. v2 loads, v1 migrates, and anything else hatches a fresh egg.

Create `applications/services/digivice/test/digivice_i18n_test.c`:

```c
// Host-side test for the digivice strings. Run: applications/services/digivice/test/run.sh
// Arguments: source files that must stay ASCII-only.
#include "../digivice_i18n.h"

#include <stdbool.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

static int failures = 0;

#define CHECK(cond)                                                \
    do {                                                           \
        if(!(cond)) {                                              \
            printf("FAIL %s:%d: %s\n", __FILE__, __LINE__, #cond); \
            failures++;                                            \
        }                                                          \
    } while(0)

static void test_width(void) {
    CHECK(digivice_i18n_text_width("") == 0);
    CHECK(digivice_i18n_text_width("A") == 3);
    CHECK(digivice_i18n_text_width("COMER") == 19);
    // Inverted exclamation + N tilde + "AM!": 5 glyphs in 7 bytes.
    CHECK(digivice_i18n_text_width("\xC2\xA1\xC3\x91" "AM!") == 19);
}

static void test_every_string_present_and_fits(void) {
    for(int lang = 0; lang < DigiviceLangCount; lang++) {
        for(int id = 0; id < DigiviceStrCount; id++) {
            const char* text = digivice_str((DigiviceLang)lang, (DigiviceStr)id);
            uint16_t width = digivice_i18n_text_width(text);
            uint16_t budget = digivice_i18n_budget((DigiviceStr)id);
            if(text[0] == '\0') printf("missing: lang %d id %d\n", lang, id);
            CHECK(text[0] != '\0');
            if(width > budget) {
                printf(
                    "too wide: lang %d id %d is %u px, budget %u\n",
                    lang,
                    id,
                    (unsigned)width,
                    (unsigned)budget);
            }
            CHECK(width <= budget);
            CHECK(budget > 0);
        }
    }
}

static void test_out_of_range_is_safe(void) {
    CHECK(digivice_str(DigiviceLangEs, DigiviceStrCount)[0] == '\0');
    CHECK(strcmp(digivice_str((DigiviceLang)7, DigiviceStrMenuFeed), "COMER") == 0);
    CHECK(strcmp(digivice_str(DigiviceLangEn, DigiviceStrMenuFeed), "FEED") == 0);
}

static void test_utf8_is_well_formed(void) {
    for(int lang = 0; lang < DigiviceLangCount; lang++) {
        for(int id = 0; id < DigiviceStrCount; id++) {
            const unsigned char* p =
                (const unsigned char*)digivice_str((DigiviceLang)lang, (DigiviceStr)id);
            for(; *p; p++) {
                if(*p < 0x80) continue;
                // Only 2-byte sequences for U+0080..U+00FF, the Latin-1 range the font holds.
                bool ok = (p[0] == 0xC2 || p[0] == 0xC3) && (p[1] & 0xC0) == 0x80;
                CHECK(ok);
                if(!ok) break;
                p++;
            }
        }
    }
}

static void test_sources_are_ascii(int argc, char** argv) {
    for(int i = 1; i < argc; i++) {
        FILE* file = fopen(argv[i], "rb");
        CHECK(file != NULL);
        if(!file) continue;
        int c;
        long line = 1;
        while((c = fgetc(file)) != EOF) {
            if(c == '\n') line++;
            bool ascii = c == '\n' || c == '\t' || c == '\r' || (c >= 0x20 && c < 0x7F);
            if(!ascii) {
                printf("non-ASCII byte 0x%02X in %s:%ld\n", (unsigned)c, argv[i], line);
                failures++;
                break;
            }
        }
        fclose(file);
    }
}

int main(int argc, char** argv) {
    test_width();
    test_every_string_present_and_fits();
    test_out_of_range_is_safe();
    test_utf8_is_well_formed();
    test_sources_are_ascii(argc, argv);

    if(failures) {
        printf("%d check(s) failed\n", failures);
        return EXIT_FAILURE;
    }
    printf("digivice_i18n: all checks passed\n");
    return EXIT_SUCCESS;
}
```

```c
uint16_t digivice_i18n_text_width(const char* text) {
    uint16_t glyphs = 0;
    for(const unsigned char* p = (const unsigned char*)text; *p; p++) {
        // UTF-8 continuation bytes are 10xxxxxx and add no glyph.
        if((*p & 0xC0) != 0x80) glyphs++;
    }
    return glyphs ? (uint16_t)(glyphs * 4 - 1) : 0;
}

uint16_t digivice_i18n_budget(DigiviceStr id) {
    return id < DigiviceStrCount ? budgets[id] : 0;
}
```

**Interfaces:**
- Consumes: the Task 2 state fields, `DigiviceResult` and `digivice_rules_is_asleep`.
- Produces:
  - `bool digivice_rules_clean(DigiviceState* s, uint32_t now);` false when there is no poop
  - `bool digivice_rules_cure(DigiviceState* s, uint32_t now);` false (refusal) when healthy

  - `digivice_rules_tick` now also drives poop, mistakes, sickness, doses and the light (decisions D2 to D7)

How the new tick works, so the tests make sense:
- Wall time is cut at every clock hour. Each piece is awake or asleep as a whole (the sleep window is whole hours: 23:00 to 07:00).
- Every awake piece first switches the light back on and clears `light_on_asleep_s`.
- Inside a piece, `apply_due` first fires any wall-clock rule that is due now: the dirty-poop mistake, then sickness from mistakes or 24 h of starvation. The step then runs to the nearest next event: hunger or mood decay (mood at x2 while sick or with >= 3 piles), a corruption hour (also while sick), the next poop (Baby and later, below the cap), a wall-clock deadline, or the light-on hour while asleep.
- After the loop, the second dose is armed when this tick's window crossed `sick_since + 12 h`.

```c
void digivice_draw_poops(Canvas* canvas, uint8_t count, int32_t x, int32_t y, uint32_t frame) {
    for(uint8_t i = 0; i < count; i++) {
        int32_t px = x + i * 8;
        dv_bitmap(canvas, px, y, poop_rows, 7, 6);
        // Two stink dots rising and resetting every 8 frames.
        int32_t q = (int32_t)((frame + i * 3) % 8);
        dv_dot(canvas, px + 1 + (q & 1), y - 1 - q);
        dv_dot(canvas, px + 5 - (q & 1), y - 1 - (q + 4) % 8);
    }
}

void digivice_draw_dither(
    Canvas* canvas,
    int32_t x,
    int32_t y,
    int32_t w,
    int32_t h,
    uint8_t level) {
    for(int32_t j = y; j < y + h; j++) {
        for(int32_t i = x; i < x + w; i++) {
            if(bayer4[j & 3][i & 3] < level) dv_dot(canvas, i, j);

void digivice_draw_zzz(Canvas* canvas, int32_t x, int32_t y, uint32_t frame) {
    for(int32_t i = 0; i < 3; i++) {

        int32_t q = (int32_t)((frame + (uint32_t)i * 7) % 20);
        digivice_draw_text(canvas, x + q * 14 / 20 + i * 2, y - q * 16 / 20, "Z");
    }
}

void digivice_draw_night_sky(Canvas* canvas, int32_t top, int32_t bottom, uint32_t frame) {
    // x = 92 keeps the moon clear of the home screen's meter box at x >= 106.
```

```c
static void digivice_main_open(DigiviceApp* app) {

    DigiviceResult result;
    switch(app->menu_index) {
    case DigiviceIconFeed:
        digivice_app_notice(

        break;
    case DigiviceIconTrain:

        } else {
            digivice_app_notice(app, DigiviceStrNoticeNoVirux);
        }
        break;

        digivice_app_refresh(app);
        if(result == DigiviceResultOk) {
            digivice_app_notice(app, DigiviceStrCleanDone);

static void digivice_main_input(DigiviceApp* app, const InputEvent* event) {
    if(event->type != InputTypeShort && event->type != InputTypeRepeat) return;

    uint8_t index = app->menu_index;
    if(event->key == InputKeyLeft) {
        index = (index + DigiviceIconCount - 1) % DigiviceIconCount;
    } else if(event->key == InputKeyRight) {
        index = (index + 1) % DigiviceIconCount;
    } else if(event->key == InputKeyUp || event->key == InputKeyDown) {
        index = (index + DigiviceIconCount / 2) % DigiviceIconCount;
    } else if(event->type == InputTypeShort && event->key == InputKeyBack) {
        app->running = false;
    } else if(event->type == InputTypeShort && event->key == InputKeyOk) {
        digivice_main_open(app);
    }
    if(index != app->menu_index) {
        app->menu_index = index;
        // The icon's name shows briefly, so every icon explains itself.
        digivice_app_notice(app, (DigiviceStr)(DigiviceStrMenuFeed + index));
    }
}

        break;

        break;

        digivice_profile_draw(canvas, app);

static void digivice_app_input(DigiviceApp* app, const InputEvent* event) {
    switch(app->screen) {
    case DigiviceScreenMain:
        digivice_main_input(app, event);
        break;
    case DigiviceScreenTrain:
        digivice_train_input(app, event);
        break;
    case DigiviceScreenBattle:
        digivice_battle_input(app, event);
        break;
    case DigiviceScreenProfile:
        if(event->type == InputTypeShort &&
           (event->key == InputKeyBack || event->key == InputKeyOk)) {
            digivice_app_set_screen(app, DigiviceScreenMain);
        }
        break;
    case DigiviceScreenSettings:
        digivice_settings_input(app, event);
        break;
    case DigiviceScreenEvolution:
        break;
    case DigiviceScreenError:
        if(event->type == InputTypeShort && event->key == InputKeyBack) app->running = false;
        break;
    }
}

static void digivice_app_tick(DigiviceApp* app) {
    app->frame++;
    app->screen_frame++;
    if(app->notice_frames) app->notice_frames--;

    switch(app->screen) {
    case DigiviceScreenMain:
    case DigiviceScreenProfile:
    case DigiviceScreenSettings:
        if(app->frame % 10 == 0) digivice_app_refresh(app);
        break;
    case DigiviceScreenTrain:
        digivice_train_tick(app);
        break;
    case DigiviceScreenBattle:
        digivice_battle_tick(app);
        break;
    case DigiviceScreenEvolution:
        if(app->screen_frame > DIGIVICE_EVO_FRAMES) {
            digivice_ack_evolution(app->digivice);
            app->state.evo_from = DigiviceFormNone;
            digivice_app_set_screen(app, DigiviceScreenMain);
        }
        break;
    case DigiviceScreenError:
        break;
    }
}

int32_t digivice_app(void* p) {
    UNUSED(p);
    DigiviceApp* app = malloc(sizeof(DigiviceApp));
    memset(app, 0, sizeof(DigiviceApp));
    app->running = true;
    app->mutex = furi_mutex_alloc(FuriMutexTypeNormal);
    app->input_queue = furi_message_queue_alloc(8, sizeof(InputEvent));
    app->notification = furi_record_open(RECORD_NOTIFICATION);

    if(furi_record_exists(RECORD_DIGIVICE)) {
        app->digivice = furi_record_open(RECORD_DIGIVICE);
        digivice_app_set_screen(app, DigiviceScreenMain);
        digivice_app_refresh(app);
        digivice_app_notice(app, DigiviceStrMenuFeed);
    } else {
        FURI_LOG_E(TAG, "Digivice service is not running");
        digivice_app_set_screen(app, DigiviceScreenError);
    }

    app->view_port = view_port_alloc();
    view_port_draw_callback_set(app->view_port, digivice_app_draw_callback, app);
    view_port_input_callback_set(app->view_port, digivice_app_input_callback, app);
    app->gui = furi_record_open(RECORD_GUI);
    gui_add_view_port(app->gui, app->view_port, GuiLayerFullscreen);

    uint32_t frame_ticks = furi_ms_to_ticks(DIGIVICE_APP_FRAME_MS);
    uint32_t last_tick = furi_get_tick();
    while(app->running) {
        InputEvent event;
        bool got_input = furi_message_queue_get(app->input_queue, &event, frame_ticks) ==
                         FuriStatusOk;

        furi_check(furi_mutex_acquire(app->mutex, FuriWaitForever) == FuriStatusOk);
        if(got_input) digivice_app_input(app, &event);
        if(furi_get_tick() - last_tick >= frame_ticks) {
            last_tick += frame_ticks;
            digivice_app_tick(app);
        }
        furi_mutex_release(app->mutex);
        view_port_update(app->view_port);
    }

    notification_message(app->notification, &sequence_reset_rgb);
    gui_remove_view_port(app->gui, app->view_port);
    view_port_free(app->view_port);
    furi_record_close(RECORD_GUI);
    if(app->digivice) furi_record_close(RECORD_DIGIVICE);
    furi_record_close(RECORD_NOTIFICATION);
    furi_message_queue_free(app->input_queue);
    furi_mutex_free(app->mutex);
    free(app);
    return 0;
}
```

```c
static void digivice_settings_change(DigiviceApp* app) {
    if(app->setting == DigiviceSettingLanguage) {
        uint8_t lang = (app->state.lang + 1) % DigiviceLangCount;
        digivice_set_lang(app->digivice, (DigiviceLang)lang);

    }

void digivice_settings_input(DigiviceApp* app, const InputEvent* event) {
    if(event->type != InputTypeShort) return;

    if(app->confirm) {
        // The reset needs OK twice; any other key backs out.
        if(event->key == InputKeyOk && app->confirm == 1) {
            app->confirm = 2;
        } else if(event->key == InputKeyOk) {
            digivice_reset(app->digivice);
            app->confirm = 0;
            app->menu_index = DigiviceIconFeed;
            digivice_app_set_screen(app, DigiviceScreenMain);
            digivice_app_refresh(app);
            digivice_app_notice(app, DigiviceStrResetDone);
        } else {
            app->confirm = 0;
        }
        return;
    }

    switch(event->key) {
    case InputKeyUp:
        app->setting = (app->setting + DigiviceSettingCount - 1) % DigiviceSettingCount;
        break;
    case InputKeyDown:
        app->setting = (app->setting + 1) % DigiviceSettingCount;
        break;
    case InputKeyLeft:
    case InputKeyRight:
        digivice_settings_change(app);
        break;
    case InputKeyOk:
```

```c
#include "digivice_app_i.h"

// Frame marks of the care animations, at 10 fps.
#define CLEAN_SWEEP_END  12
#define LIGHT_YAWN_END   6
#define LIGHT_DIM_END    14
#define CURE_SLIDE_END   8
#define CURE_PUSH_END    16
#define CURE_SPARKLE_END 22

void digivice_care_start(DigiviceApp* app, DigiviceCare care) {
    app->care = care;
    app->care_frame = 0;
    app->notice_frames = 0;
}

void digivice_care_tick(DigiviceApp* app) {
    app->care_frame++;
    if(app->care_frame >= DIGIVICE_CARE_FRAMES) {
        app->care = DigiviceCareNone;
        digivice_app_refresh(app);
    }
}

static void digivice_care_hearts(Canvas* canvas, int32_t x, uint32_t t) {
    for(int32_t i = 0; i < 2; i++) {
        int32_t q = (int32_t)((t + (uint32_t)i * 5) % 10);
        digivice_draw_heart(canvas, x + 10 + i * 8, 24 - q);
    }
}

static void digivice_care_clean(Canvas* canvas, DigiviceApp* app, int32_t pet_x) {
    uint32_t f = app->care_frame;
    if(f < CLEAN_SWEEP_END) {
        int32_t x = 128 - (int32_t)f * 140 / CLEAN_SWEEP_END;
        digivice_draw_sweep(canvas, x, 13, 52, app->frame);
    } else {
        digivice_care_hearts(canvas, pet_x, f - CLEAN_SWEEP_END);
        digivice_draw_label(canvas, 14, digivice_app_str(app, DigiviceStrCleanDone));
    }
}

static uint8_t digivice_care_dark_level(const DigiviceApp* app) {
    uint32_t f = app->care_frame;
    const uint32_t dim = LIGHT_DIM_END - LIGHT_YAWN_END;
    // Lights off: a yawn, then the band dims to 12/16. Lights on: it brightens straight away.
    if(app->care == DigiviceCareLightOff) {
        if(f < LIGHT_YAWN_END) return 0;
        if(f >= LIGHT_DIM_END) return 12;
        return (uint8_t)((f - LIGHT_YAWN_END) * 12 / dim);
    }
    return f < dim ? (uint8_t)(12 - f * 12 / dim) : 0;
}

static void digivice_care_light(Canvas* canvas, DigiviceApp* app, int32_t pet_x) {
    uint32_t f = app->care_frame;
    bool off = app->care == DigiviceCareLightOff;
    uint8_t level = digivice_care_dark_level(app);
    if(level) digivice_draw_dark(canvas, 12, 52, level, app->frame);

    canvas_set_color(canvas, level >= 12 ? ColorWhite : ColorBlack);
    digivice_draw_zzz(canvas, pet_x + 12, 26, app->frame);
    canvas_set_color(canvas, ColorBlack);

    if(off && f < LIGHT_YAWN_END) {
        digivice_draw_label(canvas, 14, digivice_app_str(app, DigiviceStrLightYawn));
    } else if(off && f >= LIGHT_DIM_END) {
        digivice_draw_label(canvas, 14, digivice_app_str(app, DigiviceStrLightNight));
    } else if(!off && level == 0) {
        digivice_draw_label(canvas, 14, digivice_app_str(app, DigiviceStrLightOn));
    }
}

static void digivice_care_cure(Canvas* canvas, DigiviceApp* app, int32_t pet_x) {
    uint32_t f = app->care_frame;
    bool cured = !app->state.sick;
    if(f < CURE_PUSH_END) {
        int32_t slide = f < CURE_SLIDE_END ? (int32_t)f : CURE_SLIDE_END;
        int32_t x = 120 - slide * 52 / CURE_SLIDE_END;
        int32_t push = f < CURE_SLIDE_END ? 0 : (int32_t)(f - CURE_SLIDE_END);
        digivice_draw_syringe(canvas, x - 6, 37, push);
    }
    // The skull keeps showing until the sparkles, then only if a dose is still missing.
    if(cured && f < CURE_PUSH_END) digivice_draw_skull(canvas, pet_x - 3, 18);
    if(f >= CURE_SLIDE_END + 6 && f < CURE_SPARKLE_END) {
        digivice_draw_sparkle_ring(canvas, pet_x, 34, 16, 10, f);
    }
    if(f >= CURE_SPARKLE_END - 4) {
        if(cured) digivice_care_hearts(canvas, pet_x, f);
        digivice_draw_label(
            canvas,
            14,
            digivice_app_str(app, cured ? DigiviceStrCureDone : DigiviceStrCureMoreDose));
    }
}

void digivice_care_draw(Canvas* canvas, DigiviceApp* app, int32_t pet_x) {
    switch(app->care) {
    case DigiviceCareClean:
        digivice_care_clean(canvas, app, pet_x);
        break;
    case DigiviceCareLightOff:
    case DigiviceCareLightOn:
        digivice_care_light(canvas, app, pet_x);
        break;
    case DigiviceCareCure:
        digivice_care_cure(canvas, app, pet_x);
        break;
    default:
        break;
    }
}
```
