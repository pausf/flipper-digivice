# Digivice Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the stock Flipper Zero firmware into a digivice-style virtual pet that lives on the home screen, grows from real deeds, needs care, and fights VIRUX enemies, without removing any stock feature.

**Architecture:** A pure-C rules module (`digivice_rules.c`, no furi) holds every game rule and is covered by a host test compiled with the system `cc`. A new `digivice_srv` service owns the persisted state, listens to a new dolphin deed pubsub, ticks every 60 s and drives LED/vibro/buzzer. The desktop swaps the dolphin animation view for a HUD-cyber pet view, and short Right opens a built-in `digivice` app (menu, feed, training, stats, battle, evolution cutscene). Shared canvas drawing lives in `digivice_draw.c`.

**Tech Stack:** C (gnu17 on target, c11 on host), Flipper furi core (`FuriEventLoop`, `FuriPubSub`, `FuriMutex`), GUI `Canvas`/`View`/`ViewPort`, `saved_struct`, notification service, fbt app manifests.

**Spec:** `docs/superpowers/specs/2026-10-13-digivice-design.md`

## Global Constraints

- Keep the upstream diff minimal: new code goes in new files; stock files get the smallest possible edits (dolphin: 4 small hunks, desktop: 3 files, a few lines each, two `.fam` lines, two `api_symbols.csv` lines each).
- Bluetooth, the mobile app, qFlipper, RPC, storage and updater stay untouched.
- Never block dolphin: the deed pubsub callback uses `furi_message_queue_put(..., 0)`; a full queue drops the deed.
- Display is 128x64, 1-bit. Colour comes only from the RGB LED; feel from vibration and buzzer.
- Every tuning number lives in `applications/services/digivice/digivice_config.h`.
- `digivice_rules.h` / `digivice_rules.c` / `digivice_config.h` have NO furi includes; they compile on the host.
- Host tests: `cc -std=c11 -Wall -Wextra -Werror ...` via `applications/services/digivice/test/run.sh`; output binary goes to `$TMPDIR`, never into the repo.
- The agent never runs `./fbt` (no build, no flash). Every firmware-touching task ends with a **Device check (user)** step: the user runs `./fbt flash_usb_full` and verifies the listed behaviour.
- Work on branch `digivice` (Task 1 creates it).
- Commits: Conventional Commits, one per task, NO `Co-Authored-By` and no AI attribution lines. Stage explicit paths only (never `git add .` / `git add -A`).
- Match the repo style: 4-space indent, `if(` without space, `.clang-format` column limit 99. Comment only non-obvious code.
- Form names (BYTEEGG, BITLING, BYTEMON, TAGDRAKE, WAVEDRAKE, BEAMDRAKE, PLUGDRAKE, VIRUBYTE) are our own; no licensed Digimon names or art.

## Decisions that resolve spec gaps

These were open or unworkable in the spec; the plan implements them as stated.

1. **The app is `apptype=SYSTEM`, not `APP`.** `loader_find_application_by_name()` (`applications/services/loader/loader.c:371-390`) searches only SETTINGS, SYSTEM and DEBUG lists, so an `APP` can never be started with `loader_start("digivice")`. SYSTEM apps are built in, startable by appid, and hidden from the main menu, so the app appears exactly once: behind short Right. The `"digivice"` entry stays in `main_apps` `provides`.
2. **Service appid is `digivice_srv`**, because appids are unique and the app owns `digivice`.
3. **Short Right:** if the user configured a Right-short favourite in Desktop settings, that still wins (no stock feature removed); otherwise it opens `digivice` (this replaces the Passport fallback). Dummy (game) mode keeps its stock behaviour.
4. **Dolphin level-up with a hidden dolphin view:** the level-up needs `animation_manager_interact_process()`, which only ran on Right presses over the dolphin view. The Right handler now calls it twice (pending -> active -> idle) before opening the app, so `dolphin_upgrade_level()` still runs and no press is swallowed.
5. **Status bar:** the desktop status bar is drawn over rows 0..12, so the home HUD starts at row 13 and shows no clock of its own.
6. **Sub-hour accounting:** the state keeps awake-second accumulators for hunger, mood and corruption; a tick advances event by event, so 60 s ticks lose nothing and corruption starts exactly when hunger or mood hits 0. Corruption, like decay, pauses in the sleep window. Hour of day is `(timestamp % 86400) / 3600` because `furi_hal_rtc_get_timestamp()` encodes local RTC time.
7. **Feeding at full hunger is refused** (returns false, no corruption drop), otherwise spamming Feed would erase corruption.
8. **Battle numbers the spec left open** (player HP, VIRUX HP/ATK and base damage per stage, base reward 10 EXP) are in `digivice_config.h`. A corrupt pet fights at its pre-corruption stage.
9. **Extra persisted fields:** `born_at` (hatch timer), `evo_from` (pending cutscene), the three accumulators, and `reserved` padding.
10. **Sprites are drawing functions** ported from the mockup's `mon()` / `foe()` with canvas primitives, not bitmaps. Poses: idle (2-frame breathing + blink), attack (open mouth, caller lunges), hit (caller blinks the sprite), corrupted (VIRUBYTE form + glitch overlay at corruption >= 50).
11. **Flash wear:** the service only marks the state dirty when something other than tick bookkeeping changed. The saved snapshot is always self-consistent, so replaying from its `last_tick` after a reboot is exact.
12. **Evolution buzzer** plays when the evolution happens (service); the cutscene plays the next time the home view or the app is shown, and is acknowledged at its end.

```c
// Pure game rules: no furi includes, so the host test can compile this file with plain cc.

#include <stdbool.h>
#include <stdint.h>

#include <dolphin/helpers/dolphin_deed.h>

#ifdef __cplusplus
extern "C" {
#endif

typedef enum {
    DigiviceTypeNfc,
    DigiviceTypeSubGhz,
    DigiviceTypeIr,
    DigiviceTypeUsb,
    DigiviceTypeCount,
    DigiviceTypeNone = 0xFF,
} DigiviceType;

typedef enum {
    DigiviceFormByteegg,
    DigiviceFormBitling,
    DigiviceFormBytemon,
    DigiviceFormTagdrake,
    DigiviceFormWavedrake,
    DigiviceFormBeamdrake,
    DigiviceFormPlugdrake,
    DigiviceFormVirubyte,
    DigiviceFormCount,
    DigiviceFormNone = 0xFF,
} DigiviceForm;

typedef enum {
    DigiviceStageEgg,
    DigiviceStageBaby,
    DigiviceStageRookie,
    DigiviceStageChampion,
    DigiviceStageCount,
} DigiviceStage;

typedef enum {
    DigiviceBattleResultWin,
    DigiviceBattleResultLose,
    DigiviceBattleResultFled,
} DigiviceBattleResult;

typedef enum {
    DigiviceBattleOngoing,
    DigiviceBattleWon,
    DigiviceBattleLost,
} DigiviceBattleOutcome;

/** Persisted pet state. Fixed-width fields only: it is written as-is by saved_struct. */
typedef struct {
    uint8_t form; /**< DigiviceForm */
    uint8_t prev_form; /**< form to restore after corruption recovery */
    uint8_t evo_from; /**< form before the last evolution, DigiviceFormNone when none is pending */
    uint8_t hunger; /**< 0..DIGIVICE_HUNGER_MAX */
    uint8_t mood; /**< 0..DIGIVICE_MOOD_MAX */
    uint8_t corruption; /**< 0..DIGIVICE_CORRUPTION_MAX */
    uint8_t virux_type; /**< DigiviceType, DigiviceTypeNone when no VIRUX is pending */
    uint8_t reserved;
    uint16_t strength;
    uint16_t wins;
    uint16_t losses;
    uint16_t data[DigiviceTypeCount];
    uint32_t exp;
    uint32_t virux_expires;
    uint32_t last_tick;
    uint32_t born_at;
    uint32_t clean_since; /**< when corruption last reached 0, 0 while corruption > 0 */
    // Awake seconds carried between ticks so 60 s ticks lose nothing to rounding.
    uint32_t hunger_acc_s;
    uint32_t mood_acc_s;
    uint32_t corrupt_acc_s;
} DigiviceState;

typedef struct {
    uint16_t player_hp;
    uint16_t player_hp_max;
    uint16_t foe_hp;
    uint16_t foe_hp_max;
    uint8_t player_type;
    uint8_t foe_type;
    uint8_t stage;
    bool defending;
} DigiviceBattle;

void digivice_rules_init(DigiviceState* s, uint32_t now);

DigiviceStage digivice_rules_stage(const DigiviceState* s);
DigiviceType digivice_rules_player_type(const DigiviceState* s);
DigiviceType digivice_rules_deed_type(DolphinDeed deed);
bool digivice_rules_is_spawn_deed(DolphinDeed deed);
bool digivice_rules_is_sleep_hour(uint8_t hour);
uint32_t digivice_rules_awake_seconds(uint32_t from, uint32_t to);

/** Applies time-based rules from s->last_tick to now. */
void digivice_rules_tick(DigiviceState* s, uint32_t now);

/** Grants EXP and data for a deed and rolls a VIRUX spawn (rng_pct 0..99). True on spawn. */
bool digivice_rules_on_deed(
    DigiviceState* s,
    DolphinDeed deed,
    uint8_t weight,
    uint32_t now,
    uint8_t rng_pct);

/** Advances at most one evolution stage. Returns true when the form changed. */
bool digivice_rules_evolve(DigiviceState* s, uint32_t now);

/** Returns false (and changes nothing) when hunger is already full. */
bool digivice_rules_feed(DigiviceState* s, uint32_t now);
void digivice_rules_train(DigiviceState* s, bool success, uint32_t now);
void digivice_rules_battle_result(DigiviceState* s, DigiviceBattleResult result, uint32_t now);
void digivice_rules_ack_evolution(DigiviceState* s);

bool digivice_rules_virux_active(const DigiviceState* s, uint32_t now);
bool digivice_rules_glitchy(const DigiviceState* s);
bool digivice_rules_attack_misses(const DigiviceState* s, uint8_t rng_pct);
bool digivice_rules_timing_hit(uint8_t cursor, uint8_t zone_start);

/** True when two states differ only in tick bookkeeping, so the service can skip a flash write. */
bool digivice_rules_same_visible(const DigiviceState* a, const DigiviceState* b);

uint16_t digivice_rules_type_x10(DigiviceType attacker, DigiviceType defender);
uint16_t digivice_rules_damage(
    uint16_t base,
    uint16_t strength,
    bool in_zone,
    DigiviceType attacker,
    DigiviceType defender);

void digivice_battle_init(DigiviceBattle* b, const DigiviceState* s);
/** Returns the damage dealt, 0 on a corruption miss. */
uint16_t digivice_battle_player_attack(

    bool in_zone,

void digivice_battle_defend(DigiviceBattle* b);

uint16_t digivice_battle_foe_attack(DigiviceBattle* b);
DigiviceBattleOutcome digivice_battle_outcome(const DigiviceBattle* b);
```

```c
// Host-side test for the pure digivice rules. Run: applications/services/digivice/test/run.sh
#include "../digivice_rules.h"
#include "../digivice_config.h"

#include <stdio.h>
#include <stdlib.h>

static int failures = 0;

#define CHECK(cond)                                                \
    do {                                                           \
        if(!(cond)) {                                              \
            printf("FAIL %s:%d: %s\n", __FILE__, __LINE__, #cond); \
            failures++;                                            \
        }                                                          \
    } while(0)

#define H(n)   ((uint32_t)(n) * 3600UL)
#define DAY(n) ((uint32_t)(n) * 86400UL)

// Day 10 at 08:00, a wide-awake starting point.
#define T0 (DAY(10) + H(8))

static DigiviceState fresh(uint32_t now) {
    DigiviceState s;
    digivice_rules_init(&s, now);
    return s;
}

static DigiviceState rookie(uint32_t now) {
    DigiviceState s = fresh(now);
    s.form = DigiviceFormBytemon;
    s.exp = DIGIVICE_ROOKIE_EXP;
    return s;
}

static void test_init(void) {
    DigiviceState s = fresh(T0);
    CHECK(s.form == DigiviceFormByteegg);
    CHECK(s.hunger == DIGIVICE_HUNGER_MAX);
    CHECK(s.mood == DIGIVICE_MOOD_MAX);
    CHECK(s.corruption == 0);
    CHECK(s.virux_type == DigiviceTypeNone);
    CHECK(s.evo_from == DigiviceFormNone);
    CHECK(s.last_tick == T0 && s.born_at == T0);
}

static void test_hunger_decays_every_2h(void) {
    DigiviceState s = fresh(T0);
    digivice_rules_tick(&s, T0 + H(2) - 1);
    CHECK(s.hunger == 4);
    digivice_rules_tick(&s, T0 + H(2));
    CHECK(s.hunger == 3);
    digivice_rules_tick(&s, T0 + H(4));
    CHECK(s.hunger == 2);
}

static void test_mood_decays_every_3h(void) {
    DigiviceState s = fresh(T0);
    digivice_rules_tick(&s, T0 + H(3) - 1);
    CHECK(s.mood == 4);
    digivice_rules_tick(&s, T0 + H(3));
    CHECK(s.mood == 3);
}

static void test_60s_ticks_lose_nothing(void) {
    DigiviceState s = fresh(T0);
    for(uint32_t t = T0 + 60; t <= T0 + H(6); t += 60)
        digivice_rules_tick(&s, t);
    CHECK(s.hunger == 1);
    CHECK(s.mood == 2);
}

static void test_sleep_window(void) {
    CHECK(digivice_rules_is_sleep_hour(23));
    CHECK(digivice_rules_is_sleep_hour(0));
    CHECK(digivice_rules_is_sleep_hour(6));
    CHECK(!digivice_rules_is_sleep_hour(7));
    CHECK(!digivice_rules_is_sleep_hour(22));

    // 22:00 -> 08:00 has one awake hour before 23:00 and one after 07:00.
    CHECK(digivice_rules_awake_seconds(DAY(10) + H(22), DAY(11) + H(8)) == H(2));

    DigiviceState s = fresh(DAY(10) + H(23));
    digivice_rules_tick(&s, DAY(11) + H(7));
    CHECK(s.hunger == 4);
    CHECK(s.mood == 4);
}

static void test_elapsed_clamped_to_48h(void) {
    DigiviceState a = fresh(T0);
    DigiviceState b = fresh(T0);
    digivice_rules_tick(&a, T0 + H(48));
    digivice_rules_tick(&b, T0 + DAY(30));
    CHECK(a.hunger == b.hunger && a.mood == b.mood && a.corruption == b.corruption);
    CHECK(b.last_tick == T0 + DAY(30));
}

static void test_clock_backwards_is_zero_elapsed(void) {
    DigiviceState s = fresh(T0);
    digivice_rules_tick(&s, T0 - H(5));
    CHECK(s.hunger == 4 && s.mood == 4);
    CHECK(s.last_tick == T0 - H(5));
}

static void test_corruption_grows_5_per_hour_at_zero(void) {
    DigiviceState s = rookie(T0);
    s.hunger = 0;
    digivice_rules_tick(&s, T0 + H(1) - 60);
    CHECK(s.corruption == 0);
    digivice_rules_tick(&s, T0 + H(1));
    CHECK(s.corruption == 5);
    digivice_rules_tick(&s, T0 + H(3));
    CHECK(s.corruption == 15);

    DigiviceState m = rookie(T0);
    m.mood = 0;
    digivice_rules_tick(&m, T0 + H(2));
    CHECK(m.corruption == 10);
}

static void test_corruption_starts_when_hunger_hits_zero(void) {
    DigiviceState s = rookie(T0);
    s.hunger = 1;
    s.mood = 4;
    // Hunger reaches 0 at +2h, then 1h more of starvation adds 5.
    digivice_rules_tick(&s, T0 + H(3));
    CHECK(s.hunger == 0);
    CHECK(s.corruption == 5);
}

static void test_feed(void) {
    DigiviceState s = rookie(T0);
    s.hunger = 2;
    s.corruption = 12;
    CHECK(digivice_rules_feed(&s, T0));
    CHECK(s.hunger == 3);
    CHECK(s.corruption == 7);
    s.hunger = DIGIVICE_HUNGER_MAX;
    CHECK(!digivice_rules_feed(&s, T0));
```

```c
static uint32_t min_u32(uint32_t a, uint32_t b) {
    return a < b ? a : b;
}

static void add_u16(uint16_t* value, uint32_t amount) {
    uint32_t sum = (uint32_t)*value + amount;
    *value = sum > UINT16_MAX ? UINT16_MAX : (uint16_t)sum;
}

static void evolve_to(DigiviceState* s, uint8_t form) {
    s->evo_from = s->form;
    s->form = form;
}

static void set_corruption(DigiviceState* s, int32_t value, uint32_t now) {
    if(value < 0) value = 0;
    if(value > DIGIVICE_CORRUPTION_MAX) value = DIGIVICE_CORRUPTION_MAX;
    s->corruption = (uint8_t)value;

    if(value > 0) {
        s->clean_since = 0;
    } else if(s->clean_since == 0) {
        s->clean_since = now;
    }

    if(value == DIGIVICE_CORRUPTION_MAX && s->form != DigiviceFormVirubyte &&
       digivice_rules_stage(s) >= DigiviceStageRookie) {
        s->prev_form = s->form;
        evolve_to(s, DigiviceFormVirubyte);
    }
}

    s->form = DigiviceFormByteegg;
    s->prev_form = DigiviceFormByteegg;
    s->evo_from = DigiviceFormNone;
    s->hunger = DIGIVICE_HUNGER_MAX;
    s->mood = DIGIVICE_MOOD_MAX;
    s->virux_type = DigiviceTypeNone;

    s->born_at = now;
    s->clean_since = now;

DigiviceStage digivice_rules_stage(const DigiviceState* s) {
    uint8_t form = s->form == DigiviceFormVirubyte ? s->prev_form : s->form;
    switch(form) {
    case DigiviceFormByteegg:
        return DigiviceStageEgg;
    case DigiviceFormBitling:
        return DigiviceStageBaby;
    case DigiviceFormBytemon:
        return DigiviceStageRookie;
    default:
        return DigiviceStageChampion;
    }
}

bool digivice_rules_is_sleep_hour(uint8_t hour) {
    return hour >= DIGIVICE_SLEEP_START_HOUR || hour < DIGIVICE_SLEEP_END_HOUR;
}

uint32_t digivice_rules_awake_seconds(uint32_t from, uint32_t to) {
    uint32_t awake = 0;
    uint32_t t = from;
    while(t < to) {
        uint32_t next = min_u32((t / 3600UL + 1UL) * 3600UL, to);
        uint8_t hour = (uint8_t)((t % 86400UL) / 3600UL);
        if(!digivice_rules_is_sleep_hour(hour)) awake += next - t;
        t = next;
    }
    return awake;
}

void digivice_rules_tick(DigiviceState* s, uint32_t now) {
    uint32_t elapsed = now > s->last_tick ? now - s->last_tick : 0;
    elapsed = min_u32(elapsed, DIGIVICE_ELAPSED_MAX_S);
    uint32_t awake = digivice_rules_awake_seconds(now - elapsed, now);

    // Advance event by event so corruption only accrues while hunger or mood is really zero.
    while(awake > 0) {
        uint32_t step = awake;
        if(s->hunger > 0) step = min_u32(step, DIGIVICE_HUNGER_DECAY_S - s->hunger_acc_s);
        if(s->mood > 0) step = min_u32(step, DIGIVICE_MOOD_DECAY_S - s->mood_acc_s);

        if(s->hunger > 0) s->hunger_acc_s += step;
        if(s->mood > 0) s->mood_acc_s += step;
        if(s->hunger == 0 || s->mood == 0) s->corrupt_acc_s += step;
        awake -= step;

        if(s->hunger_acc_s >= DIGIVICE_HUNGER_DECAY_S) {
            s->hunger_acc_s = 0;
            s->hunger--;
        }
        if(s->mood_acc_s >= DIGIVICE_MOOD_DECAY_S) {
            s->mood_acc_s = 0;
            s->mood--;
        }
        if(s->corrupt_acc_s >= 3600UL) {
            uint32_t hours = s->corrupt_acc_s / 3600UL;
            s->corrupt_acc_s %= 3600UL;
            set_corruption(
                s, (int32_t)s->corruption + (int32_t)(hours * DIGIVICE_CORRUPTION_PER_HOUR), now);
        }
    }

    if(s->virux_type != DigiviceTypeNone && now >= s->virux_expires) {
        s->virux_type = DigiviceTypeNone;
    }

    if(s->form == DigiviceFormVirubyte && s->corruption == 0 && s->clean_since != 0 &&
       now >= s->clean_since && now - s->clean_since >= DIGIVICE_CORRUPTION_RECOVERY_S) {
        evolve_to(s, s->prev_form);
    }

    s->last_tick = now;
}

bool digivice_rules_feed(DigiviceState* s, uint32_t now) {
    if(s->hunger >= DIGIVICE_HUNGER_MAX) return false;
    s->hunger++;
    set_corruption(s, (int32_t)s->corruption - DIGIVICE_CORRUPTION_FEED_DROP, now);
    return true;
}

void digivice_rules_train(DigiviceState* s, bool success, uint32_t now) {
    if(s->hunger > 0) s->hunger--;
    if(!success) return;
    add_u16(&s->strength, 1);
    if(s->mood < DIGIVICE_MOOD_MAX) s->mood++;
    set_corruption(s, (int32_t)s->corruption - DIGIVICE_CORRUPTION_TRAIN_DROP, now);
}

bool digivice_rules_glitchy(const DigiviceState* s) {
    return s->corruption >= DIGIVICE_CORRUPTION_GLITCH;
}

bool digivice_rules_attack_misses(const DigiviceState* s, uint8_t rng_pct) {
    return digivice_rules_glitchy(s) && rng_pct < DIGIVICE_CORRUPTION_MISS_PCT;
}

bool digivice_rules_timing_hit(uint8_t cursor, uint8_t zone_start) {
    return cursor >= zone_start && cursor < zone_start + DIGIVICE_METER_ZONE;
}

bool digivice_rules_same_visible(const DigiviceState* a, const DigiviceState* b) {
    DigiviceState x = *a;
    DigiviceState y = *b;
    x.last_tick = y.last_tick = 0;
    x.hunger_acc_s = y.hunger_acc_s = 0;
    x.mood_acc_s = y.mood_acc_s = 0;
    x.corrupt_acc_s = y.corrupt_acc_s = 0;
    return memcmp(&x, &y, sizeof(DigiviceState)) == 0;
}
```

```c
    case DolphinDeedIrLearnSuccess:
    case DolphinDeedIrSave:
        return DigiviceTypeIr;

    case DolphinDeedBadUsbPlayScript:
    case DolphinDeedU2fAuthorized:
    case DolphinDeedGpioUartBridge:
        return DigiviceTypeUsb;

    default:
        return DigiviceTypeNone;
    }
}

bool digivice_rules_is_spawn_deed(DolphinDeed deed) {
    return deed == DolphinDeedNfcRead || deed == DolphinDeedRfidRead ||
           deed == DolphinDeedIbuttonRead || deed == DolphinDeedSubGhzReceiverInfo ||
           deed == DolphinDeedSubGhzFrequencyAnalyzer;
}

bool digivice_rules_virux_active(const DigiviceState* s, uint32_t now) {
    return s->virux_type != DigiviceTypeNone && now < s->virux_expires;
}

bool digivice_rules_on_deed(
    DigiviceState* s,
    DolphinDeed deed,
    uint8_t weight,
    uint32_t now,
    uint8_t rng_pct) {
    if(deed >= DolphinDeedMAX) return false;

    s->exp += weight;
    DigiviceType type = digivice_rules_deed_type(deed);
    if(type == DigiviceTypeNone) return false;
    add_u16(&s->data[type], 1);

    bool eligible = digivice_rules_is_spawn_deed(deed) &&
                    digivice_rules_stage(s) >= DigiviceStageRookie &&
                    !digivice_rules_virux_active(s, now);
    if(!eligible || rng_pct >= DIGIVICE_SPAWN_PCT) return false;

    s->virux_type = type;
    s->virux_expires = now + DIGIVICE_VIRUX_TTL_S;
    return true;
}

bool digivice_rules_evolve(DigiviceState* s, uint32_t now) {
    switch(s->form) {
    case DigiviceFormByteegg:
        if(now >= s->born_at && now - s->born_at >= DIGIVICE_HATCH_S) {
            evolve_to(s, DigiviceFormBitling);
            return true;
        }
        return false;
    case DigiviceFormBitling:
        if(s->exp >= DIGIVICE_ROOKIE_EXP) {
            evolve_to(s, DigiviceFormBytemon);
            return true;
        }
        return false;
    case DigiviceFormBytemon:
        if(s->exp >= DIGIVICE_CHAMPION_EXP) {
            // Strict > keeps the first type on ties: NFC, SUBGHZ, IR, USB.
            uint8_t best = DigiviceTypeNfc;
            for(uint8_t t = 1; t < DigiviceTypeCount; t++) {
                if(s->data[t] > s->data[best]) best = t;
            }
            evolve_to(s, champion_of[best]);
            return true;
        }
        return false;
    default:
        return false;
    }
}

void digivice_rules_ack_evolution(DigiviceState* s) {
    s->evo_from = DigiviceFormNone;
}
```

```c
static const uint16_t base_damage[DigiviceStageCount] = DIGIVICE_BASE_DAMAGE;
static const uint16_t player_hp[DigiviceStageCount] = DIGIVICE_PLAYER_HP;
static const uint16_t virux_hp[DigiviceStageCount] = DIGIVICE_VIRUX_HP;
static const uint16_t virux_atk[DigiviceStageCount] = DIGIVICE_VIRUX_ATK;

// The type each attacker type is strong against: NFC > USB > IR > SUBGHZ > NFC.
static const uint8_t beats[DigiviceTypeCount] = {
    [DigiviceTypeNfc] = DigiviceTypeUsb,
    [DigiviceTypeUsb] = DigiviceTypeIr,
    [DigiviceTypeIr] = DigiviceTypeSubGhz,
    [DigiviceTypeSubGhz] = DigiviceTypeNfc,
};

void digivice_rules_battle_result(DigiviceState* s, DigiviceBattleResult result, uint32_t now) {
    if(result == DigiviceBattleResultWin) {
        s->exp += 2 * DIGIVICE_WIN_BASE_EXP;
        if(s->virux_type < DigiviceTypeCount) add_u16(&s->data[s->virux_type], DIGIVICE_WIN_DATA);
        add_u16(&s->wins, 1);
    } else if(result == DigiviceBattleResultLose) {
        add_u16(&s->losses, 1);
        set_corruption(s, (int32_t)s->corruption + DIGIVICE_CORRUPTION_LOSE_GAIN, now);
    }
    s->virux_type = DigiviceTypeNone;
}

uint16_t digivice_rules_type_x10(DigiviceType attacker, DigiviceType defender) {
    if(attacker >= DigiviceTypeCount || defender >= DigiviceTypeCount) return 10;
    return beats[attacker] == defender ? DIGIVICE_TYPE_ADV_X10 : 10;
}

uint16_t digivice_rules_damage(
    uint16_t base,
    uint16_t strength,
    bool in_zone,
    DigiviceType attacker,
    DigiviceType defender) {
    uint32_t timing = in_zone ? DIGIVICE_TIMING_HIT_X10 : DIGIVICE_TIMING_MISS_X10;
    uint32_t damage =
        ((uint32_t)base + strength) * timing * digivice_rules_type_x10(attacker, defender) / 100;
    if(damage == 0) damage = 1;
    return damage > UINT16_MAX ? UINT16_MAX : (uint16_t)damage;
}

void digivice_battle_init(DigiviceBattle* b, const DigiviceState* s) {
    DigiviceStage stage = digivice_rules_stage(s);
    b->stage = stage;
    b->player_type = digivice_rules_player_type(s);
    b->foe_type = s->virux_type;
    b->player_hp_max = b->player_hp = player_hp[stage];
    b->foe_hp_max = b->foe_hp = virux_hp[stage];
    b->defending = false;
}

static void hurt(uint16_t* hp, uint16_t damage) {
    *hp = damage >= *hp ? 0 : *hp - damage;
}

uint16_t digivice_battle_player_attack(
    DigiviceBattle* b,
    const DigiviceState* s,
    bool in_zone,
    uint8_t rng_pct) {
    if(digivice_rules_attack_misses(s, rng_pct)) return 0;
    uint16_t damage = digivice_rules_damage(
        base_damage[b->stage],
        s->strength,
        in_zone,
        (DigiviceType)b->player_type,
        (DigiviceType)b->foe_type);
    hurt(&b->foe_hp, damage);
    return damage;
}

void digivice_battle_defend(DigiviceBattle* b) {
    b->defending = true;
}

bool digivice_battle_flee(uint8_t rng_pct) {
    return rng_pct < DIGIVICE_FLEE_PCT;
}

uint16_t digivice_battle_foe_attack(DigiviceBattle* b) {
    uint32_t damage =
        (uint32_t)virux_atk[b->stage] *
        digivice_rules_type_x10((DigiviceType)b->foe_type, (DigiviceType)b->player_type) / 10;
    if(b->defending) damage /= 2;
    if(damage == 0) damage = 1;
    b->defending = false;
    hurt(&b->player_hp, (uint16_t)damage);
    return (uint16_t)damage;
}

DigiviceBattleOutcome digivice_battle_outcome(const DigiviceBattle* b) {
    if(b->foe_hp == 0) return DigiviceBattleWon;
    if(b->player_hp == 0) return DigiviceBattleLost;
    return DigiviceBattleOngoing;
}
```

```c
#include "digivice_i.h"
#include "digivice_config.h"
#include "digivice_notify.h"

#include <furi_hal.h>
#include <toolbox/saved_struct.h>

#define TAG "Digivice"

#define DIGIVICE_STATE_PATH    INT_PATH(".digivice.state")
#define DIGIVICE_STATE_MAGIC   0xD1
#define DIGIVICE_STATE_VERSION 0x01

#define DIGIVICE_QUEUE_SIZE 16
#define DIGIVICE_DONE_FLAG  (0x1)

// Public API

FuriPubSub* digivice_get_pubsub(Digivice* digivice) {
    furi_check(digivice);
    return digivice->pubsub;
}

void digivice_get_state(Digivice* digivice, DigiviceState* state) {
    furi_check(digivice);
    furi_check(state);
    furi_check(furi_mutex_acquire(digivice->mutex, FuriWaitForever) == FuriStatusOk);
    *state = digivice->state;
    furi_mutex_release(digivice->mutex);
}

static void digivice_send_wait(Digivice* digivice, DigiviceMessage* message) {
    message->flag = furi_event_flag_alloc();
    furi_check(furi_message_queue_put(digivice->queue, message, FuriWaitForever) == FuriStatusOk);
    furi_check(
        furi_event_flag_wait(message->flag, DIGIVICE_DONE_FLAG, FuriFlagWaitAny, FuriWaitForever) ==
        DIGIVICE_DONE_FLAG);
    furi_event_flag_free(message->flag);
}

bool digivice_feed(Digivice* digivice) {
    furi_check(digivice);
    bool fed = false;
    DigiviceMessage message = {.type = DigiviceMessageTypeFeed, .result = &fed};
    digivice_send_wait(digivice, &message);
    return fed;
}

void digivice_train(Digivice* digivice, bool success) {
    furi_check(digivice);
    DigiviceMessage message = {.type = DigiviceMessageTypeTrain, .success = success};
    digivice_send_wait(digivice, &message);
}

void digivice_battle_finish(Digivice* digivice, DigiviceBattleResult result) {
    furi_check(digivice);
    DigiviceMessage message = {.type = DigiviceMessageTypeBattle, .battle = result};
    digivice_send_wait(digivice, &message);
}

void digivice_ack_evolution(Digivice* digivice) {
    furi_check(digivice);
    DigiviceMessage message = {.type = DigiviceMessageTypeAckEvolution};
    furi_message_queue_put(digivice->queue, &message, 0);
}

// Private

static void digivice_load(Digivice* digivice) {
    DigiviceState loaded;
    bool ok = saved_struct_load(
        DIGIVICE_STATE_PATH,
        &loaded,
        sizeof(DigiviceState),
        DIGIVICE_STATE_MAGIC,
        DIGIVICE_STATE_VERSION);
    if(ok && (loaded.form >= DigiviceFormCount || loaded.prev_form >= DigiviceFormCount)) {
        ok = false;
    }

    furi_check(furi_mutex_acquire(digivice->mutex, FuriWaitForever) == FuriStatusOk);
    if(ok) {
        digivice->state = loaded;
        digivice->dirty = false;
    } else {
        FURI_LOG_W(TAG, "No valid state, hatching a new egg");
        digivice_rules_init(&digivice->state, furi_hal_rtc_get_timestamp());
        digivice->dirty = true;
    }
    furi_mutex_release(digivice->mutex);
    digivice->storage_ready = true;
    if(digivice->dirty)
        furi_event_loop_timer_start(digivice->flush_timer, DIGIVICE_FLUSH_S * 1000UL);
}

static void digivice_save(Digivice* digivice) {
    if(!digivice->dirty || !digivice->storage_ready) return;

    DigiviceState snapshot;
    digivice_get_state(digivice, &snapshot);
    if(saved_struct_save(
           DIGIVICE_STATE_PATH,
           &snapshot,
           sizeof(DigiviceState),
           DIGIVICE_STATE_MAGIC,
           DIGIVICE_STATE_VERSION)) {
        digivice->dirty = false;
    } else {
        FURI_LOG_E(TAG, "Failed to save state");
    }
}

static void digivice_publish(Digivice* digivice) {
    DigiviceState snapshot;
    digivice_get_state(digivice, &snapshot);
    furi_pubsub_publish(digivice->pubsub, &snapshot);
}

/** Runs `before` vs current state bookkeeping after any mutation done under the mutex. */
static void digivice_changed(Digivice* digivice, const DigiviceState* before) {
    DigiviceState after;
    digivice_get_state(digivice, &after);
    if(digivice_rules_same_visible(before, &after)) return;

    if(after.evo_from != DigiviceFormNone && after.evo_from != before->evo_from) {
        notification_message(digivice->notification, &digivice_sequence_evolution);
    }
    digivice->dirty = true;
    furi_event_loop_timer_start(digivice->flush_timer, DIGIVICE_FLUSH_S * 1000UL);
    digivice_publish(digivice);
}

static void digivice_tick(void* context) {
    Digivice* digivice = context;

    if(!digivice->storage_ready && storage_sd_status(digivice->storage) == FSE_OK) {
        digivice_load(digivice);
        digivice_publish(digivice);
    }

    uint32_t now = furi_hal_rtc_get_timestamp();
    furi_check(furi_mutex_acquire(digivice->mutex, FuriWaitForever) == FuriStatusOk);
    DigiviceState before = digivice->state;
    digivice_rules_tick(&digivice->state, now);
    digivice_rules_evolve(&digivice->state, now);
    furi_mutex_release(digivice->mutex);

    digivice_changed(digivice, &before);
}

static void digivice_flush(void* context) {
    digivice_save(context);
}

static void digivice_process_message(FuriEventLoopObject* object, void* context) {
    UNUSED(object);
    Digivice* digivice = context;
    DigiviceMessage message;
    furi_check(furi_message_queue_get(digivice->queue, &message, 0) == FuriStatusOk);

    if(message.type == DigiviceMessageTypeReload) {
        // Only the first mount loads; later remounts keep the live pet and save over the card.
        if(!digivice->storage_ready) {
            digivice_load(digivice);
            digivice_publish(digivice);
        }
        return;
    }

    uint32_t now = furi_hal_rtc_get_timestamp();
    bool spawned = false;

    furi_check(furi_mutex_acquire(digivice->mutex, FuriWaitForever) == FuriStatusOk);
    DigiviceState before = digivice->state;
    DigiviceState* state = &digivice->state;

    switch(message.type) {
    case DigiviceMessageTypeDeed:
        // Test deeds sit above DolphinDeedMAX and have no weight entry.
        if(message.deed < DolphinDeedMAX) {
            spawned = digivice_rules_on_deed(
                state,
                message.deed,
                dolphin_deed_get_weight(message.deed),
                now,
                (uint8_t)(furi_hal_random_get() % 100));
            digivice_rules_evolve(state, now);
            FURI_LOG_D(TAG, "Deed %d: exp %lu", (int)message.deed, (unsigned long)state->exp);
        }
        break;
    case DigiviceMessageTypeFeed:
        *message.result = digivice_rules_feed(state, now);
        break;
    case DigiviceMessageTypeTrain:
        digivice_rules_train(state, message.success, now);
        break;
    case DigiviceMessageTypeBattle:
        digivice_rules_battle_result(state, message.battle, now);
        digivice_rules_evolve(state, now);
        break;
    case DigiviceMessageTypeAckEvolution:
        digivice_rules_ack_evolution(state);
        break;
    default:
        break;
    }
    furi_mutex_release(digivice->mutex);

    if(spawned) notification_message(digivice->notification, &digivice_sequence_virux);
    digivice_changed(digivice, &before);

    if(message.flag) furi_event_flag_set(message.flag, DIGIVICE_DONE_FLAG);
}

static void digivice_deed_callback(const void* message, void* context) {
    Digivice* digivice = context;
    DigiviceMessage event = {
        .type = DigiviceMessageTypeDeed,
        .deed = *(const DolphinDeed*)message,
    };
    // Never block dolphin: a full queue drops the deed.
    furi_message_queue_put(digivice->queue, &event, 0);
}

static void digivice_storage_callback(const void* message, void* context) {
    Digivice* digivice = context;
    const StorageEvent* storage_event = message;
    if(storage_event->type != StorageEventTypeCardMount) return;
    DigiviceMessage event = {.type = DigiviceMessageTypeReload};
    // The tick retries the load if this one is dropped.
    furi_message_queue_put(digivice->queue, &event, 0);
}

static Digivice* digivice_alloc(void) {
    Digivice* digivice = malloc(sizeof(Digivice));
    digivice->mutex = furi_mutex_alloc(FuriMutexTypeNormal);
    digivice->pubsub = furi_pubsub_alloc();
    digivice->queue = furi_message_queue_alloc(DIGIVICE_QUEUE_SIZE, sizeof(DigiviceMessage));
    digivice->event_loop = furi_event_loop_alloc();
    digivice->tick_timer = furi_event_loop_timer_alloc(
        digivice->event_loop, digivice_tick, FuriEventLoopTimerTypePeriodic, digivice);
    digivice->flush_timer = furi_event_loop_timer_alloc(
        digivice->event_loop, digivice_flush, FuriEventLoopTimerTypeOnce, digivice);
    digivice->notification = furi_record_open(RECORD_NOTIFICATION);
    digivice->storage = furi_record_open(RECORD_STORAGE);
    digivice_rules_init(&digivice->state, furi_hal_rtc_get_timestamp());
    return digivice;
}

int32_t digivice_srv(void* p) {
    UNUSED(p);

    if(furi_hal_rtc_get_boot_mode() != FuriHalRtcBootModeNormal) {
        FURI_LOG_W(TAG, "Skipping start in special boot mode");
        furi_thread_suspend(furi_thread_get_current_id());
        return 0;
    }

    Digivice* digivice = digivice_alloc();
    if(storage_sd_status(digivice->storage) == FSE_OK) digivice_load(digivice);
    furi_record_create(RECORD_DIGIVICE, digivice);

    digivice->storage_subscription = furi_pubsub_subscribe(
        storage_get_pubsub(digivice->storage), digivice_storage_callback, digivice);

    Dolphin* dolphin = furi_record_open(RECORD_DOLPHIN);
    digivice->deed_subscription =
        furi_pubsub_subscribe(dolphin_get_deed_pubsub(dolphin), digivice_deed_callback, digivice);
    furi_record_close(RECORD_DOLPHIN);

    furi_event_loop_subscribe_message_queue(
        digivice->event_loop,
        digivice->queue,
        FuriEventLoopEventIn,
        digivice_process_message,
        digivice);

    furi_event_loop_timer_start(digivice->tick_timer, DIGIVICE_TICK_S * 1000UL);
    // Catch up on the time the Flipper was off before the first periodic tick.
    furi_event_loop_pend_callback(digivice->event_loop, digivice_tick, digivice);

    furi_event_loop_run(digivice->event_loop);
    return 0;
}
```

```c
#include "digivice_draw.h"
#include "digivice_config.h"

#include <stdio.h>
#include <u8g2.h>

// sin(i * 22.5 deg) * 64, so rotations stay in integer math.
static const int8_t sin16[16] =
    {0, 24, 45, 59, 64, 59, 45, 24, 0, -24, -45, -59, -64, -59, -45, -24};
// Breathing offset over 8 frames.
static const int8_t wobble[8] = {0, 1, 1, 1, 0, -1, -1, -1};

static int32_t dv_sin(uint32_t i) {
    return sin16[i & 15];
}

static int32_t dv_cos(uint32_t i) {
    return sin16[(i + 4) & 15];
}

// Cheap deterministic hash so glitches look random but need no RNG.
static uint32_t dv_hash(uint32_t x) {
    x ^= x >> 16;
    x *= 0x7feb352dUL;
    x ^= x >> 15;
    x *= 0x846ca68bUL;
    x ^= x >> 16;
    return x;
}

void digivice_draw_text(Canvas* canvas, int32_t x, int32_t y, const char* text) {
    canvas_set_custom_u8g2_font(canvas, u8g2_font_4x6_tr);
    canvas_draw_str(canvas, x, y + 5, text);
}

uint16_t digivice_draw_text_width(Canvas* canvas, const char* text) {
    canvas_set_custom_u8g2_font(canvas, u8g2_font_4x6_tr);
    return canvas_string_width(canvas, text);
}

void digivice_draw_fill_ellipse(Canvas* canvas, int32_t cx, int32_t cy, int32_t rx, int32_t ry) {
    if(rx < 0 || ry < 0) return;
    if(ry == 0) {
        canvas_draw_line(canvas, cx - rx, cy, cx + rx, cy);
        return;
    }
    for(int32_t y = -ry; y <= ry; y++) {
        // Largest hw with (hw/rx)^2 + (y/ry)^2 <= 1.
        int32_t hw = rx;
        while(hw > 0 && hw * hw * ry * ry + y * y * rx * rx > rx * rx * ry * ry)
            hw--;
        canvas_draw_line(canvas, cx - hw, cy + y, cx + hw, cy + y);
    }
}

static int32_t dv_edge(int32_t px, int32_t py, int32_t qx, int32_t qy, int32_t x, int32_t y) {
    return (qx - px) * (y - py) - (qy - py) * (x - px);
}

static int32_t dv_min3(int32_t a, int32_t b, int32_t c) {
    int32_t m = a < b ? a : b;
    return m < c ? m : c;
}

static int32_t dv_max3(int32_t a, int32_t b, int32_t c) {
    int32_t m = a > b ? a : b;
    return m > c ? m : c;
}

void digivice_draw_fill_triangle(
    Canvas* canvas,
    int32_t ax,
    int32_t ay,
    int32_t bx,
    int32_t by,
    int32_t cx,
    int32_t cy) {
    for(int32_t y = dv_min3(ay, by, cy); y <= dv_max3(ay, by, cy); y++) {
        for(int32_t x = dv_min3(ax, bx, cx); x <= dv_max3(ax, bx, cx); x++) {
            int32_t w0 = dv_edge(bx, by, cx, cy, x, y);
            int32_t w1 = dv_edge(cx, cy, ax, ay, x, y);
            int32_t w2 = dv_edge(ax, ay, bx, by, x, y);
            if((w0 >= 0 && w1 >= 0 && w2 >= 0) || (w0 <= 0 && w1 <= 0 && w2 <= 0)) {
                canvas_draw_dot(canvas, x, y);
            }
        }
    }
}

void digivice_draw_ring(Canvas* canvas, int32_t cx, int32_t cy, int32_t rx, int32_t ry) {
    canvas_set_color(canvas, ColorBlack);
    digivice_draw_fill_ellipse(canvas, cx, cy, rx, ry);
    canvas_set_color(canvas, ColorWhite);
    digivice_draw_fill_ellipse(canvas, cx, cy, rx - 1, ry - 1);
    canvas_set_color(canvas, ColorBlack);
}

void digivice_draw_brackets(
    Canvas* canvas,
    int32_t x0,
    int32_t y0,
    int32_t x1,
    int32_t y1,
    int32_t len) {
    canvas_draw_line(canvas, x0, y0, x0 + len - 1, y0);
    canvas_draw_line(canvas, x0, y0, x0, y0 + len - 1);
    canvas_draw_line(canvas, x1 - len + 1, y0, x1, y0);
    canvas_draw_line(canvas, x1, y0, x1, y0 + len - 1);
    canvas_draw_line(canvas, x0, y1, x0 + len - 1, y1);
    canvas_draw_line(canvas, x0, y1 - len + 1, x0, y1);
    canvas_draw_line(canvas, x1 - len + 1, y1, x1, y1);
    canvas_draw_line(canvas, x1, y1 - len + 1, x1, y1);
}

// Clips the far end of a floor ray to the screen edge so u8g2 never sees wild coordinates.
static void dv_floor_ray(Canvas* canvas, int32_t x0, int32_t y0, int32_t x1, int32_t y1) {
    if(x1 < 0) {
        y1 = y0 + (y1 - y0) * (0 - x0) / (x1 - x0);
        x1 = 0;
    } else if(x1 > 127) {
        y1 = y0 + (y1 - y0) * (127 - x0) / (x1 - x0);
        x1 = 127;
    }
    canvas_draw_line(canvas, x0, y0, x1, y1);
}

void digivice_draw_grid(Canvas* canvas, int32_t horizon, uint32_t frame) {
    int32_t depth = 63 - horizon;
    for(int32_t i = -8; i <= 8; i++) {
        dv_floor_ray(canvas, 64 + i * 4, horizon, 64 + i * 26, 63);
    }
    for(int32_t k = 0; k < 6; k++) {
        int32_t z = k * 8 + (int32_t)(frame % 8);
        canvas_draw_line(
            canvas,
            0,
            horizon + z * z * depth / (48 * 48),
            127,
            horizon + z * z * depth / (48 * 48));
    }
    canvas_draw_line(canvas, 0, horizon, 127, horizon);
}

void digivice_draw_glitch(Canvas* canvas, uint32_t seed, uint8_t strips) {
    canvas_set_color(canvas, ColorXOR);
    for(uint8_t k = 0; k < strips; k++) {
        uint32_t r = dv_hash(seed * 31 + k);
        int32_t y = (int32_t)(r % 60);
        int32_t h = 1 + (int32_t)((r >> 8) % 3);
        int32_t x = (int32_t)((r >> 12) % 96);
        int32_t w = 16 + (int32_t)((r >> 20) % 32);
        canvas_draw_box(canvas, x, y, w, h);
    }
    canvas_set_color(canvas, ColorBlack);
}

void digivice_draw_scanline(Canvas* canvas, uint32_t frame) {
    int32_t y = (int32_t)((frame * 3) % 90);
    if(y >= 64) return;
    canvas_set_color(canvas, ColorXOR);
    canvas_draw_line(canvas, 0, y, 127, y);
    canvas_set_color(canvas, ColorBlack);
}

static void dv_eyes_and_mouth(
    Canvas* canvas,
    int32_t cx,
    int32_t by,
    int32_t k10,
    uint32_t frame,
    DigivicePose pose) {
    bool blink = (frame % 32) == 0;
    for(int32_t sd = -1; sd <= 1; sd += 2) {
        int32_t ex = cx + 2 + sd * 3 * k10 / 10;
        int32_t ey = by - 1;
        if(blink) {
            canvas_draw_line(canvas, ex - 1, ey, ex + 1, ey);
        } else {
            canvas_draw_box(canvas, ex - 1, ey - 2, 3, 4);
            canvas_set_color(canvas, ColorWhite);
            canvas_draw_dot(canvas, ex, ey - 1);
            canvas_set_color(canvas, ColorBlack);
        }
    }
    int32_t mx = cx + 1;
    int32_t my = by + 3;
    if(pose == DigivicePoseAttack) {
        canvas_draw_box(canvas, mx - 1, my, 5, 3);
    } else {
        canvas_draw_dot(canvas, mx - 1, my);
        canvas_draw_dot(canvas, mx, my + 1);
        canvas_draw_dot(canvas, mx + 1, my);
        canvas_draw_dot(canvas, mx + 2, my + 1);
        canvas_draw_dot(canvas, mx + 3, my);
    }
}

// Port of the mockup's mon(): the byte-sized dragon every rookie and champion form is built on.
static void dv_mon(
    Canvas* canvas,
    int32_t cx,
    int32_t cy,
    uint32_t frame,
    bool big,
    bool silhouette,
    DigivicePose pose) {
    int32_t k10 = big ? 14 : 10;
    int32_t br = wobble[frame % 8];
    int32_t rx = 8 * k10 / 10;
    int32_t ry = 7 * k10 / 10 - (br > 0 ? 1 : 0);
    int32_t by = cy - (br > 0 ? 1 : 0);

    if(big) {
        int32_t f = wobble[(frame * 2) % 8] * 2;
        for(int32_t sd = -1; sd <= 1; sd += 2) {
            digivice_draw_fill_triangle(
                canvas,
                cx + sd * rx / 2,
                by - 3,
                cx + sd * (rx + 11),
                by - 13 + f,
                cx + sd * (rx + 5),
                by + 5);
            if(!silhouette) {
                canvas_set_color(canvas, ColorWhite);
                digivice_draw_fill_triangle(
                    canvas,
                    cx + sd * (rx / 2 + 2),
                    by - 2,
                    cx + sd * (rx + 8),
                    by - 10 + f,
                    cx + sd * (rx + 4),
                    by + 2);
                canvas_set_color(canvas, ColorBlack);
                canvas_draw_line(
                    canvas, cx + sd * rx * 6 / 10, by - 2, cx + sd * (rx + 9), by - 11 + f);
            }
        }
    }

    // Tail.
    digivice_draw_fill_ellipse(canvas, cx - (rx + 1), by + 3, 3 * k10 / 10, 2 * k10 / 10);

    for(int32_t sd = -1; sd <= 1; sd += 2) {
        int32_t ex = cx + sd * 5 * k10 / 10;
        int32_t top = by - ry + 2;
        int32_t tip = big ? 9 : 5;
        digivice_draw_fill_triangle(
            canvas,
            ex - 3 * k10 / 10,
            top + 1,
            ex + 3 * k10 / 10,
            top + 1,
            ex + sd * 2 * k10 / 10,
            top - tip * k10 / 10);
        if(!silhouette && !big) {
            canvas_set_color(canvas, ColorWhite);
            digivice_draw_fill_triangle(canvas, ex - 1, top, ex + 1, top, ex + sd, top - 2);
            canvas_set_color(canvas, ColorBlack);
        }
        // Feet.
        digivice_draw_fill_ellipse(canvas, cx + sd * 4 * k10 / 10, cy + ry, 25 * k10 / 100, 1);
    }

    digivice_draw_fill_ellipse(canvas, cx, by, rx + 1, ry + 1);
    if(silhouette) return;

    canvas_set_color(canvas, ColorWhite);
    digivice_draw_fill_ellipse(canvas, cx, by, rx, ry);
    canvas_set_color(canvas, ColorBlack);
    dv_eyes_and_mouth(canvas, cx, by, k10, frame, pose);
}

static void dv_egg(Canvas* canvas, int32_t cx, int32_t cy, uint32_t frame, bool silhouette) {
    // The egg rocks every few seconds as it gets ready to hatch.
    int32_t rock = (frame % 40) < 6 ? wobble[(frame * 4) % 8] : 0;
    cx += rock;
    digivice_draw_fill_ellipse(canvas, cx, cy, 8, 10);
    if(silhouette) return;
    canvas_set_color(canvas, ColorWhite);
    digivice_draw_fill_ellipse(canvas, cx, cy, 7, 9);
    canvas_set_color(canvas, ColorBlack);
    // Zigzag crack and two data spots.
    for(int32_t i = -6; i < 6; i += 2) {
        canvas_draw_line(canvas, cx + i, cy, cx + i + 1, cy - 2);
        canvas_draw_line(canvas, cx + i + 1, cy - 2, cx + i + 2, cy);
    }
    canvas_draw_box(canvas, cx - 4, cy - 6, 2, 2);
    canvas_draw_box(canvas, cx + 2, cy + 4, 3, 2);
}

static void dv_bitling(Canvas* canvas, int32_t cx, int32_t cy, uint32_t frame, bool silhouette) {
    int32_t hop = (frame % 8) < 4 ? 0 : 1;
    cy -= hop;
    digivice_draw_fill_triangle(canvas, cx - 5, cy - 3, cx - 2, cy - 4, cx - 6, cy - 8);
    digivice_draw_fill_triangle(canvas, cx + 5, cy - 3, cx + 2, cy - 4, cx + 6, cy - 8);
    digivice_draw_fill_ellipse(canvas, cx, cy, 7, 5);
    if(silhouette) return;
    canvas_set_color(canvas, ColorWhite);
    digivice_draw_fill_ellipse(canvas, cx, cy, 6, 4);
    canvas_set_color(canvas, ColorBlack);
    bool blink = (frame % 32) == 0;
    canvas_draw_box(canvas, cx - 3, cy - 1, 2, blink ? 1 : 2);
    canvas_draw_box(canvas, cx + 2, cy - 1, 2, blink ? 1 : 2);
    canvas_draw_line(canvas, cx - 1, cy + 2, cx + 1, cy + 2);
}

// Champion emblems sit on the big mon's chest or head and tell the four types apart.
static void dv_emblem(Canvas* canvas, DigiviceForm form, int32_t cx, int32_t cy) {
    switch(form) {
    case DigiviceFormTagdrake:
        // NFC: antenna coil on the chest.
        canvas_draw_frame(canvas, cx - 3, cy + 5, 7, 4);
        canvas_draw_dot(canvas, cx, cy + 6);
        break;
    case DigiviceFormWavedrake:
        // Sub-GHz: a sine wave across the belly.
        for(int32_t i = -5; i <= 5; i++)
            canvas_draw_dot(canvas, cx + i, cy + 7 + (wobble[(i + 8) % 8] > 0 ? -1 : 1));
        break;
    case DigiviceFormBeamdrake:
        // IR: a visor over the eyes with a slit.
        canvas_draw_box(canvas, cx - 7, cy - 4, 15, 4);
        canvas_set_color(canvas, ColorWhite);
        canvas_draw_line(canvas, cx - 5, cy - 2, cx + 5, cy - 2);
        canvas_set_color(canvas, ColorBlack);
        break;
    case DigiviceFormPlugdrake:
        // USB: two plug prongs on the head.
        canvas_draw_box(canvas, cx - 3, cy - 15, 2, 4);
        canvas_draw_box(canvas, cx + 2, cy - 15, 2, 4);
        canvas_draw_box(canvas, cx - 4, cy - 12, 9, 2);
        break;
    default:
        break;
    }
}

static void dv_virubyte(
    Canvas* canvas,
    int32_t cx,
    int32_t cy,
    uint32_t frame,
    bool silhouette,
    DigivicePose pose) {
    // Spikes along the back, then the mon body filled black with hollow X eyes.
    for(int32_t i = -2; i <= 2; i++) {
        digivice_draw_fill_triangle(
            canvas,
            cx + i * 4 - 2,
            cy - 6,
            cx + i * 4 + 2,
            cy - 6,
            cx + i * 4,
            cy - 12 - (i & 1) * 2);
    }
    dv_mon(canvas, cx, cy, frame, false, true, pose);
    if(silhouette) return;
    canvas_set_color(canvas, ColorWhite);
    for(int32_t sd = -1; sd <= 1; sd += 2) {
        int32_t ex = cx + 2 + sd * 3;
        canvas_draw_line(canvas, ex - 1, cy - 3, ex + 1, cy - 1);
        canvas_draw_line(canvas, ex + 1, cy - 3, ex - 1, cy - 1);
    }
    if(pose == DigivicePoseAttack) {
        canvas_draw_box(canvas, cx, cy + 2, 5, 3);
    } else {
        canvas_draw_line(canvas, cx - 1, cy + 3, cx + 4, cy + 3);
    }
    canvas_set_color(canvas, ColorBlack);
}

void digivice_draw_form(
    Canvas* canvas,
    DigiviceForm form,
    int32_t cx,
    int32_t cy,
    uint32_t frame,
    DigivicePose pose,
    bool silhouette) {
    canvas_set_color(canvas, ColorBlack);
    switch(form) {
    case DigiviceFormByteegg:
        dv_egg(canvas, cx, cy, frame, silhouette);
        break;
    case DigiviceFormBitling:
        dv_bitling(canvas, cx, cy, frame, silhouette);
        break;
    case DigiviceFormBytemon:
        dv_mon(canvas, cx, cy, frame, false, silhouette, pose);
        break;
    case DigiviceFormTagdrake:
    case DigiviceFormWavedrake:
    case DigiviceFormBeamdrake:
    case DigiviceFormPlugdrake:
        dv_mon(canvas, cx, cy, frame, true, silhouette, pose);
        if(!silhouette) dv_emblem(canvas, form, cx, cy);
        break;
    case DigiviceFormVirubyte:
        dv_virubyte(canvas, cx, cy, frame, silhouette, pose);
        break;
    default:
        break;
    }
}

// Port of the mockup's foe().
void digivice_draw_virux(Canvas* canvas, int32_t cx, int32_t cy, uint32_t frame) {
    int32_t f = wobble[(frame * 3) % 8] * 3;
    canvas_set_color(canvas, ColorBlack);
    for(int32_t sd = -1; sd <= 1; sd += 2) {
        digivice_draw_fill_triangle(
            canvas, cx + sd * 5, cy - 2, cx + sd * 17, cy - 7 + f, cx + sd * 12, cy + 5);
        digivice_draw_fill_triangle(
            canvas, cx + sd * 12, cy + 5, cx + sd * 15, cy + 1 + f / 2, cx + sd * 17, cy - 7 + f);
    }
    digivice_draw_fill_ellipse(canvas, cx, cy, 7, 6);
    digivice_draw_fill_triangle(canvas, cx - 2, cy - 5, cx - 4, cy - 11, cx - 5, cy - 4);
    digivice_draw_fill_triangle(canvas, cx + 2, cy - 5, cx + 4, cy - 11, cx + 5, cy - 4);
    canvas_set_color(canvas, ColorWhite);
    digivice_draw_fill_triangle(canvas, cx - 5, cy - 2, cx - 1, cy, cx - 5, cy + 1);
    digivice_draw_fill_triangle(canvas, cx + 5, cy - 2, cx + 1, cy, cx + 5, cy + 1);
    canvas_draw_line(canvas, cx - 2, cy + 3, cx - 2, cy + 4);
    canvas_draw_line(canvas, cx + 2, cy + 3, cx + 2, cy + 4);
    canvas_set_color(canvas, ColorBlack);
}

void digivice_draw_hp_box(
    Canvas* canvas,
    int32_t x,
    int32_t y,
    const char* name,
    uint16_t hp,
    uint16_t hp_max) {
    const int32_t w = 58;
    canvas_set_color(canvas, ColorWhite);
    canvas_draw_box(canvas, x, y, w, 13);
    canvas_set_color(canvas, ColorBlack);
    digivice_draw_brackets(canvas, x, y, x + w - 1, y + 12, 3);
    digivice_draw_text(canvas, x + 3, y + 1, name);

    uint32_t pct = hp_max ? (uint32_t)hp * 100 / hp_max : 0;
    char text[6];
    snprintf(text, sizeof(text), "%lu%%", (unsigned long)pct);
    digivice_draw_text(canvas, x + w - 3 - digivice_draw_text_width(canvas, text), y + 1, text);

    uint32_t segs = hp_max ? ((uint32_t)hp * 10 + hp_max - 1) / hp_max : 0;
    for(uint32_t i = 0; i < 10; i++) {
        int32_t sx = x + 3 + (int32_t)i * 5;
        if(i < segs) {
            canvas_draw_box(canvas, sx, y + 8, 4, 3);
        } else {
            canvas_draw_box(canvas, sx, y + 10, 4, 1);
        }
    }
}

void digivice_draw_meter(Canvas* canvas, int32_t x, int32_t y, uint8_t zone_start, uint8_t cursor) {
    for(uint8_t i = 0; i < DIGIVICE_METER_SEGMENTS; i++) {
        int32_t sx = x + i * 5;
        if(digivice_rules_timing_hit(i, zone_start)) {
            canvas_draw_frame(canvas, sx, y, 4, 6);
        } else {
            canvas_draw_box(canvas, sx, y + 4, 4, 2);
        }
    }
    canvas_draw_box(canvas, x + cursor * 5, y - 3, 4, 10);
}

static void dv_vertical_meter(
    Canvas* canvas,
    int32_t x,
    int32_t bottom,
    const char* label,
    uint8_t value,
    uint8_t max) {
    digivice_draw_text(canvas, x, bottom - 4 * max - 6, label);
    for(uint8_t i = 0; i < max; i++) {
        int32_t sy = bottom - 3 - i * 4;
        if(i < value) {
            canvas_draw_box(canvas, x, sy, 3, 3);
        } else {
            canvas_draw_line(canvas, x, sy + 2, x + 2, sy + 2);
        }
    }
}

void digivice_draw_home(
    Canvas* canvas,
    const DigiviceState* state,
    uint32_t frame,
    uint32_t now,
    bool sd_ok) {
    // The desktop status bar owns rows 0..12, so the HUD starts below it.
    const int32_t horizon = 38;
    canvas_set_color(canvas, ColorBlack);
    digivice_draw_grid(canvas, horizon, frame);

    // Data rain above the floor.
    for(int32_t i = 0; i < 9; i++) {
        int32_t x = 10 + i * 13;
        int32_t y = 13 + (int32_t)((frame * 2 + i * 17) % 25);
        canvas_draw_dot(canvas, x, y);
        if(y - 3 >= 13) canvas_draw_dot(canvas, x, y - 3);
    }

    int32_t hy = 41 + wobble[(frame / 2) % 8];
    digivice_draw_ring(canvas, 64, 55, 15 + wobble[frame % 8], 3);
    digivice_draw_ring(canvas, 64, 55, 9, 2);
    digivice_draw_form(canvas, (DigiviceForm)state->form, 64, hy, frame, DigivicePoseIdle, false);
    digivice_draw_brackets(canvas, 46, hy - 17, 82, hy + 10, 4);

    canvas_set_color(canvas, ColorWhite);
    canvas_draw_box(canvas, 0, 13, 40, 9);
    canvas_set_color(canvas, ColorBlack);
    digivice_draw_text(canvas, 3, 14, digivice_form_name((DigiviceForm)state->form));
    canvas_draw_line(canvas, 3, 21, 28, 21);

    canvas_set_color(canvas, ColorWhite);
    canvas_draw_box(canvas, 106, 13, 22, 24);
    canvas_set_color(canvas, ColorBlack);
    dv_vertical_meter(canvas, 109, 36, "H", state->hunger, DIGIVICE_HUNGER_MAX);
    dv_vertical_meter(canvas, 119, 36, "M", state->mood, DIGIVICE_MOOD_MAX);

    char text[16];
    canvas_set_color(canvas, ColorWhite);
    canvas_draw_box(canvas, 0, 56, 128, 8);
    canvas_set_color(canvas, ColorBlack);
    snprintf(text, sizeof(text), "EXP %lu", (unsigned long)state->exp);
    digivice_draw_text(canvas, 2, 57, text);
    if(state->corruption > 0) {
        snprintf(text, sizeof(text), "C%u%%", (unsigned)state->corruption);
        digivice_draw_text(canvas, 96, 57, text);
    }
    if(!sd_ok) digivice_draw_text(canvas, 115, 57, "SD!");

    if(digivice_rules_virux_active(state, now) && (frame % 10) < 6) {
        uint32_t left_min = (state->virux_expires - now + 59) / 60;
        snprintf(text, sizeof(text), "!VIRUX %lum", (unsigned long)left_min);
        canvas_draw_box(canvas, 44, 56, 46, 8);
        canvas_set_color(canvas, ColorWhite);
        digivice_draw_text(canvas, 46, 57, text);
        canvas_set_color(canvas, ColorBlack);
    }

    digivice_draw_scanline(canvas, frame);
    if(digivice_rules_glitchy(state) && (frame % 12) < 2) digivice_draw_glitch(canvas, frame, 3);
}

static void dv_sparkle(Canvas* canvas, int32_t x, int32_t y, int32_t size) {
    canvas_draw_line(canvas, x - size, y, x + size, y);
    canvas_draw_line(canvas, x, y - size, x, y + size);
}

void digivice_draw_evolution(Canvas* canvas, DigiviceForm from, DigiviceForm to, uint32_t frame) {
    const int32_t cx = 64;
    canvas_set_color(canvas, ColorBlack);

    if(frame < 20 || frame >= 30) {
        // Three dashed rings rotating in alternate directions.
        for(uint32_t r = 0; r < 3; r++) {
            int32_t rad = 18 + (int32_t)r * 12 + (int32_t)(frame % 12);
            for(uint32_t i = 0; i < 16; i++) {
                if((i + r) % 3 == 0) continue;
                uint32_t a = (r % 2) ? i + frame / 2 : i + 64 - (frame / 2) % 16;
                canvas_draw_dot(
                    canvas, cx + dv_cos(a) * rad * 3 / 128, 34 + dv_sin(a) * rad * 8 / 640);
            }
        }
    }

    if(frame < 20) {
        // The old form flickers into a silhouette, faster and faster.
        uint32_t period = 5 - frame / 5;
        bool sil = frame > 3 && (frame / period) % 2;
        digivice_draw_form(canvas, from, cx, 40, frame, DigivicePoseIdle, sil);
        uint32_t n = 3 + frame / 4;
        for(uint32_t i = 0; i < n; i++) {
            uint32_t a = frame + i * 16 / n;
            int32_t rr = 22 - (int32_t)frame * 8 / 20;
            dv_sparkle(
                canvas, cx + dv_cos(a) * rr * 14 / 640, 36 + dv_sin(a) * rr * 7 / 640, 1 + (i % 2));
        }
    } else if(frame < 30) {
        // Old and new silhouettes alternate under scan bars and glitch.
        bool alt = frame % 2;
        digivice_draw_form(
            canvas, alt ? to : from, cx, alt ? 42 : 40, frame, DigivicePoseIdle, true);
        canvas_set_color(canvas, ColorXOR);
        for(int32_t k = 0; k < 3; k++) {
            canvas_draw_box(canvas, 0, (int32_t)((frame * 20 + k * 25) % 64), 128, 3);
        }
        canvas_set_color(canvas, ColorBlack);
        digivice_draw_glitch(canvas, frame, 6);
    } else {
        uint32_t t = frame - 30;
        digivice_draw_form(canvas, to, cx, 42, frame, DigivicePoseIdle, false);
        if(t < 16) {
            for(uint32_t i = 0; i < 7; i++) {
                uint32_t a = i * 2 + t;
                int32_t rr = 20 + (int32_t)t * 2;
                dv_sparkle(
                    canvas,
                    cx + dv_cos(a) * rr * 3 / 128,
                    38 + dv_sin(a) * rr * 7 / 640,
                    1 + (i % 2));
            }
        }
        // Banner slides in from the right, the name from the left.
        int32_t bx = t < 8 ? 128 - (int32_t)t * 16 : 0;
        canvas_set_color(canvas, ColorWhite);
        canvas_draw_box(canvas, bx, 0, 128, 11);
        canvas_set_color(canvas, ColorBlack);
        canvas_draw_line(canvas, bx, 0, bx + 127, 0);
        canvas_draw_line(canvas, bx, 10, bx + 127, 10);
        digivice_draw_text(canvas, bx + 38, 3, "> EVOLUTION!");
        int32_t nx = t < 8 ? -60 + (int32_t)t * 15 / 2 : 0;
        canvas_set_color(canvas, ColorWhite);
        canvas_draw_box(canvas, nx + 36, 56, 56, 8);
        canvas_set_color(canvas, ColorBlack);
        digivice_draw_text(canvas, nx + 42, 57, digivice_form_name(to));
        if(t < 2) digivice_draw_glitch(canvas, frame, 3);
    }
}
```

```c
#include "digivice_app_i.h"

#include <furi_hal.h>
#include <notification/notification_messages.h>
#include <stdio.h>

#define TAG "DigiviceApp"

static const char* const menu_labels[DigiviceMenuCount] = {"FEED", "TRAIN", "STATS", "BATTLE"};

uint8_t digivice_app_rng_pct(void) {
    return (uint8_t)(furi_hal_random_get() % 100);
}

void digivice_meter_start(DigiviceMeter* meter) {
    meter->zone_start =
        (uint8_t)(furi_hal_random_get() % (DIGIVICE_METER_SEGMENTS - DIGIVICE_METER_ZONE + 1));
    meter->cursor = 0;
    meter->direction = 1;
}

void digivice_meter_step(DigiviceMeter* meter) {
    if(meter->cursor == 0) meter->direction = 1;
    if(meter->cursor == DIGIVICE_METER_SEGMENTS - 1) meter->direction = -1;
    meter->cursor = (uint8_t)(meter->cursor + meter->direction);
}

bool digivice_meter_hit(const DigiviceMeter* meter) {
    return digivice_rules_timing_hit(meter->cursor, meter->zone_start);
}

void digivice_app_set_screen(DigiviceApp* app, DigiviceScreen screen) {
    app->screen = screen;
    app->screen_frame = 0;
}

void digivice_app_refresh(DigiviceApp* app) {
    digivice_get_state(app->digivice, &app->state);
    bool busy = app->screen == DigiviceScreenBattle || app->screen == DigiviceScreenTrain ||
                app->screen == DigiviceScreenEvolution;
    if(app->state.evo_from != DigiviceFormNone && !busy) {
        digivice_app_set_screen(app, DigiviceScreenEvolution);
    }
}

static void digivice_app_toast(DigiviceApp* app, const char* text) {
    app->toast = text;
    app->toast_frames = 15;
}

static void digivice_menu_draw(Canvas* canvas, DigiviceApp* app) {
    uint32_t now = furi_hal_rtc_get_timestamp();
    canvas_set_color(canvas, ColorBlack);
    digivice_draw_text(canvas, 3, 2, "DIGIVICE");
    canvas_draw_line(canvas, 3, 9, 34, 9);
    digivice_draw_text(canvas, 66, 2, digivice_form_name((DigiviceForm)app->state.form));

    digivice_draw_ring(canvas, 30, 50, 15, 3);
    digivice_draw_form(
        canvas, (DigiviceForm)app->state.form, 30, 38, app->frame, DigivicePoseIdle, false);
    digivice_draw_brackets(canvas, 12, 20, 48, 52, 4);

    bool virux = digivice_rules_virux_active(&app->state, now);
    for(uint8_t i = 0; i < DigiviceMenuCount; i++) {
        int32_t y = 14 + i * 11;
        const char* label = menu_labels[i];
        if(i == DigiviceMenuBattle && !virux) label = "------";
        digivice_draw_text(canvas, 72, y, label);
        if(i == app->menu_index) {
            digivice_draw_brackets(canvas, 66, y - 2, 120, y + 7, 3);
            if(i == DigiviceMenuBattle && virux && (app->frame % 10) < 5) {
                digivice_draw_text(canvas, 104, y, "!");
            }
        }
    }

    if(app->toast_frames) {
        canvas_set_color(canvas, ColorWhite);
        canvas_draw_box(canvas, 0, 56, 128, 8);
        canvas_set_color(canvas, ColorBlack);
        canvas_draw_line(canvas, 0, 56, 127, 56);
        digivice_draw_text(canvas, 3, 57, app->toast);
    }

    digivice_draw_scanline(canvas, app->frame);
    if(digivice_rules_glitchy(&app->state) && (app->frame % 12) < 2) {
        digivice_draw_glitch(canvas, app->frame, 3);
    }
}

static void digivice_menu_input(DigiviceApp* app, const InputEvent* event) {
    if(event->type != InputTypeShort && event->type != InputTypeRepeat) return;

    if(event->key == InputKeyUp) {
        app->menu_index = (app->menu_index + DigiviceMenuCount - 1) % DigiviceMenuCount;
    } else if(event->key == InputKeyDown) {
        app->menu_index = (app->menu_index + 1) % DigiviceMenuCount;
    } else if(event->key == InputKeyBack && event->type == InputTypeShort) {
        app->running = false;
    } else if(event->key == InputKeyOk && event->type == InputTypeShort) {
        switch(app->menu_index) {
        case DigiviceMenuFeed:
            digivice_app_toast(app, digivice_feed(app->digivice) ? "> HUNGER +1" : "> NOT HUNGRY");
            digivice_app_refresh(app);
            break;
        case DigiviceMenuTrain:
            digivice_train_enter(app);
            break;
        case DigiviceMenuStats:
            digivice_app_set_screen(app, DigiviceScreenStats);
            break;
        case DigiviceMenuBattle:
            digivice_app_toast(app, "> NO VIRUX NEARBY");
            break;
        default:
            break;
        }
    }
}

static void digivice_stats_draw(Canvas* canvas, DigiviceApp* app) {
    const DigiviceState* s = &app->state;
    char line[32];
    canvas_set_color(canvas, ColorBlack);
    digivice_draw_brackets(canvas, 0, 0, 127, 63, 4);
    digivice_draw_text(canvas, 4, 3, digivice_form_name((DigiviceForm)s->form));
    digivice_draw_text(canvas, 70, 3, digivice_type_name(digivice_rules_player_type(s)));
    canvas_draw_line(canvas, 4, 10, 123, 10);

    snprintf(line, sizeof(line), "EXP %lu  STR %u", (unsigned long)s->exp, (unsigned)s->strength);
    digivice_draw_text(canvas, 4, 13, line);
    snprintf(line, sizeof(line), "WIN %u  LOSE %u", (unsigned)s->wins, (unsigned)s->losses);
    digivice_draw_text(canvas, 4, 21, line);
    snprintf(
        line,
        sizeof(line),
        "HUNGER %u/%u  MOOD %u/%u",
        (unsigned)s->hunger,
        (unsigned)DIGIVICE_HUNGER_MAX,
        (unsigned)s->mood,
        (unsigned)DIGIVICE_MOOD_MAX);
    digivice_draw_text(canvas, 4, 29, line);
    snprintf(line, sizeof(line), "CORRUPTION %u%%", (unsigned)s->corruption);
    digivice_draw_text(canvas, 4, 37, line);
    snprintf(
        line,
        sizeof(line),
        "NFC%u SUB%u IR%u USB%u",
        (unsigned)s->data[DigiviceTypeNfc],
        (unsigned)s->data[DigiviceTypeSubGhz],
        (unsigned)s->data[DigiviceTypeIr],
        (unsigned)s->data[DigiviceTypeUsb]);
    digivice_draw_text(canvas, 4, 47, line);
}

static void digivice_error_draw(Canvas* canvas) {
    canvas_set_color(canvas, ColorBlack);
    digivice_draw_brackets(canvas, 8, 16, 119, 47, 4);
    digivice_draw_text(canvas, 18, 24, "DIGIVICE SERVICE");
    digivice_draw_text(canvas, 18, 32, "NOT RUNNING");
    digivice_draw_text(canvas, 18, 40, "> BACK TO EXIT");
}

static void digivice_app_draw_callback(Canvas* canvas, void* context) {
    DigiviceApp* app = context;
    furi_check(furi_mutex_acquire(app->mutex, FuriWaitForever) == FuriStatusOk);
    canvas_clear(canvas);
    switch(app->screen) {
    case DigiviceScreenMenu:
        digivice_menu_draw(canvas, app);
        break;
    case DigiviceScreenStats:
        digivice_stats_draw(canvas, app);
        break;
    case DigiviceScreenTrain:
        digivice_train_draw(canvas, app);
        break;
    case DigiviceScreenBattle:
        break;
    case DigiviceScreenEvolution:
        digivice_draw_evolution(
            canvas,
            (DigiviceForm)app->state.evo_from,
            (DigiviceForm)app->state.form,
            app->screen_frame);
        break;
    case DigiviceScreenError:
        digivice_error_draw(canvas);
        break;
    }
    furi_mutex_release(app->mutex);
}

static void digivice_app_input_callback(InputEvent* event, void* context) {
    DigiviceApp* app = context;
    furi_message_queue_put(app->input_queue, event, FuriWaitForever);
}

static void digivice_app_input(DigiviceApp* app, const InputEvent* event) {
    switch(app->screen) {
    case DigiviceScreenMenu:
        digivice_menu_input(app, event);
        break;
    case DigiviceScreenStats:
        if(event->type == InputTypeShort &&
           (event->key == InputKeyBack || event->key == InputKeyOk)) {
            digivice_app_set_screen(app, DigiviceScreenMenu);
        }
        break;
    case DigiviceScreenTrain:
        digivice_train_input(app, event);
        break;
    case DigiviceScreenBattle:
        break;
    case DigiviceScreenEvolution:
        break;
    case DigiviceScreenError:
        if(event->type == InputTypeShort && event->key == InputKeyBack) app->running = false;
        break;
    }
}

static void digivice_app_tick(DigiviceApp* app) {
    app->frame++;
    app->screen_frame++;
    if(app->toast_frames) app->toast_frames--;

    switch(app->screen) {
    case DigiviceScreenMenu:
    case DigiviceScreenStats:
        if(app->frame % 10 == 0) digivice_app_refresh(app);
        break;
    case DigiviceScreenTrain:
        digivice_train_tick(app);
        break;
    case DigiviceScreenBattle:
        break;
    case DigiviceScreenEvolution:
        if(app->screen_frame > DIGIVICE_EVO_FRAMES) {
            digivice_ack_evolution(app->digivice);
            app->state.evo_from = DigiviceFormNone;
            digivice_app_set_screen(app, DigiviceScreenMenu);
        }
        break;
    case DigiviceScreenError:
        break;
    }
}

int32_t digivice_app(void* p) {
    UNUSED(p);
    DigiviceApp* app = malloc(sizeof(DigiviceApp));
    memset(app, 0, sizeof(DigiviceApp));
    app->running = true;
    app->mutex = furi_mutex_alloc(FuriMutexTypeNormal);
    app->input_queue = furi_message_queue_alloc(8, sizeof(InputEvent));
    app->notification = furi_record_open(RECORD_NOTIFICATION);

    if(furi_record_exists(RECORD_DIGIVICE)) {
        app->digivice = furi_record_open(RECORD_DIGIVICE);
        digivice_app_set_screen(app, DigiviceScreenMenu);
        digivice_app_refresh(app);
    } else {
        FURI_LOG_E(TAG, "Digivice service is not running");
        digivice_app_set_screen(app, DigiviceScreenError);
    }

    app->view_port = view_port_alloc();
    view_port_draw_callback_set(app->view_port, digivice_app_draw_callback, app);
    view_port_input_callback_set(app->view_port, digivice_app_input_callback, app);
    app->gui = furi_record_open(RECORD_GUI);
    gui_add_view_port(app->gui, app->view_port, GuiLayerFullscreen);

    uint32_t frame_ticks = furi_ms_to_ticks(DIGIVICE_APP_FRAME_MS);
    uint32_t last_tick = furi_get_tick();
    while(app->running) {
        InputEvent event;
        bool got_input = furi_message_queue_get(app->input_queue, &event, frame_ticks) ==
                         FuriStatusOk;

        furi_check(furi_mutex_acquire(app->mutex, FuriWaitForever) == FuriStatusOk);
        if(got_input) digivice_app_input(app, &event);
        if(furi_get_tick() - last_tick >= frame_ticks) {
            last_tick += frame_ticks;
            digivice_app_tick(app);
        }
        furi_mutex_release(app->mutex);
        view_port_update(app->view_port);
    }

    notification_message(app->notification, &sequence_reset_rgb);
    gui_remove_view_port(app->gui, app->view_port);
    view_port_free(app->view_port);
    furi_record_close(RECORD_GUI);
    if(app->digivice) furi_record_close(RECORD_DIGIVICE);
    furi_record_close(RECORD_NOTIFICATION);
    furi_message_queue_free(app->input_queue);
    furi_mutex_free(app->mutex);
    free(app);
    return 0;
}
```

```c
#include "digivice_app_i.h"

#define TRAIN_RESULT_FRAMES 15

void digivice_train_enter(DigiviceApp* app) {
    digivice_meter_start(&app->meter);
    app->train_done = false;
    app->train_success = false;
    digivice_app_set_screen(app, DigiviceScreenTrain);
}

static void digivice_train_finish(DigiviceApp* app, bool success) {
    app->train_done = true;
    app->train_success = success;
    app->screen_frame = 0;
    digivice_train(app->digivice, success);
    digivice_get_state(app->digivice, &app->state);
}

void digivice_train_input(DigiviceApp* app, const InputEvent* event) {
    if(event->type != InputTypeShort || app->train_done) return;
    if(event->key == InputKeyOk) {
        digivice_train_finish(app, digivice_meter_hit(&app->meter));
    } else if(event->key == InputKeyBack) {
        // Leaving before the press costs nothing.
        digivice_app_set_screen(app, DigiviceScreenMenu);
    }
}

void digivice_train_tick(DigiviceApp* app) {
    if(app->train_done) {
        if(app->screen_frame >= TRAIN_RESULT_FRAMES) {
            digivice_app_set_screen(app, DigiviceScreenMenu);
            digivice_app_refresh(app);
        }
        return;
    }
    digivice_meter_step(&app->meter);
    if(app->screen_frame >= DIGIVICE_APP_AIM_FRAMES) digivice_train_finish(app, false);
}

void digivice_train_draw(Canvas* canvas, DigiviceApp* app) {
    canvas_set_color(canvas, ColorBlack);
    digivice_draw_text(canvas, 3, 2, "TRAINING");
    canvas_draw_line(canvas, 3, 9, 34, 9);

    // A target post on the right, the pet charging at it from the left.
    canvas_draw_frame(canvas, 96, 18, 10, 26);
    canvas_draw_line(canvas, 96, 31, 105, 31);
    bool lunge = app->train_done && app->train_success && app->screen_frame < 6;
    DigivicePose pose = lunge ? DigivicePoseAttack : DigivicePoseIdle;
    digivice_draw_form(
        canvas, (DigiviceForm)app->state.form, lunge ? 64 : 40, 34, app->frame, pose, false);
    digivice_draw_brackets(canvas, 20, 14, 112, 48, 4);

    if(!app->train_done) {
        digivice_draw_meter(canvas, 14, 55, app->meter.zone_start, app->meter.cursor);
    } else {
        digivice_draw_text(
            canvas, 14, 55, app->train_success ? "> STR +1  MOOD +1" : "> MISSED...");
        if(app->train_success && app->screen_frame < 4) {
            digivice_draw_glitch(canvas, app->frame, 4);
        }
    }
}
```

`applications/main/digivice/digivice_app_battle.c`:

```c
#include "digivice_app_i.h"
#include <digivice/digivice_notify.h>
#include <notification/notification_messages.h>

#include <stdio.h>

static const char* const choice_labels[DigiviceBattleChoiceCount] = {"ATTACK", "DEFEND", "FLEE"};

static void digivice_battle_set_phase(DigiviceApp* app, DigiviceBattlePhase phase) {
    app->phase = phase;
    app->screen_frame = 0;

    switch(phase) {
    case DigiviceBattlePhaseAim:
        digivice_meter_start(&app->meter);
        notification_message(app->notification, &digivice_sequence_charge);
        app->message = "TIME IT! PRESS OK";
        break;
    case DigiviceBattlePhaseFoeHit:
        app->last_damage = digivice_battle_foe_attack(&app->battle);
        notification_message(app->notification, &digivice_sequence_hit);
        app->message = "VIRUX STRIKES!";
        break;
    case DigiviceBattlePhaseChoose:
        app->message = NULL;
        break;
    default:
        break;
    }
}

static void
    digivice_battle_end(DigiviceApp* app, DigiviceBattleResult result, const char* message) {
    app->result = result;
    app->message = message;
    if(result == DigiviceBattleResultWin) {
        notification_message(app->notification, &digivice_sequence_win);
    }
    digivice_battle_set_phase(app, DigiviceBattlePhaseEnd);
}

static void digivice_battle_fire(DigiviceApp* app, bool in_zone) {
    app->last_damage =
        digivice_battle_player_attack(&app->battle, &app->state, in_zone, digivice_app_rng_pct());
    if(app->last_damage) {
        notification_message(app->notification, &digivice_sequence_hit);
        app->message = in_zone ? "CRITICAL BYTE!" : "GLANCING HIT";
    } else {
        notification_message(app->notification, &sequence_reset_rgb);
        app->message = "CORRUPTED... MISS!";
    }
    digivice_battle_set_phase(app, DigiviceBattlePhasePlayerHit);
}

void digivice_battle_enter(DigiviceApp* app) {
    digivice_battle_init(&app->battle, &app->state);
    app->choice = DigiviceBattleChoiceAttack;
    app->message = "A VIRUX APPEARED!";
    digivice_app_set_screen(app, DigiviceScreenBattle);
    digivice_battle_set_phase(app, DigiviceBattlePhaseIntro);
}

void digivice_battle_input(DigiviceApp* app, const InputEvent* event) {
    if(event->type != InputTypeShort) return;

    switch(app->phase) {
    case DigiviceBattlePhaseIntro:
        if(event->key == InputKeyOk) digivice_battle_set_phase(app, DigiviceBattlePhaseChoose);
        break;
    case DigiviceBattlePhaseChoose:
        if(event->key == InputKeyLeft) {
            app->choice =
                (app->choice + DigiviceBattleChoiceCount - 1) % DigiviceBattleChoiceCount;
        } else if(event->key == InputKeyRight) {
            app->choice = (app->choice + 1) % DigiviceBattleChoiceCount;
        } else if(event->key == InputKeyOk) {
            if(app->choice == DigiviceBattleChoiceAttack) {
                digivice_battle_set_phase(app, DigiviceBattlePhaseAim);
            } else if(app->choice == DigiviceBattleChoiceDefend) {
                digivice_battle_defend(&app->battle);
                digivice_battle_set_phase(app, DigiviceBattlePhaseFoeHit);
            } else if(digivice_battle_flee(digivice_app_rng_pct())) {
                digivice_battle_end(app, DigiviceBattleResultFled, "GOT AWAY SAFELY");
            } else {
                digivice_battle_set_phase(app, DigiviceBattlePhaseFoeHit);
            }
        }
        break;
    case DigiviceBattlePhaseAim:
        if(event->key == InputKeyOk) digivice_battle_fire(app, digivice_meter_hit(&app->meter));
        break;
    case DigiviceBattlePhaseEnd:
        if(event->key == InputKeyOk || event->key == InputKeyBack) {
            digivice_battle_finish(app->digivice, app->result);
            digivice_app_set_screen(app, DigiviceScreenMenu);
            digivice_app_refresh(app);
        }
        break;
    default:
        break;
    }
}

void digivice_battle_tick(DigiviceApp* app) {
    switch(app->phase) {
    case DigiviceBattlePhaseIntro:
        if(app->screen_frame >= 15) digivice_battle_set_phase(app, DigiviceBattlePhaseChoose);
        break;
    case DigiviceBattlePhaseAim:
        digivice_meter_step(&app->meter);
        if(app->screen_frame >= DIGIVICE_APP_AIM_FRAMES) digivice_battle_fire(app, false);
        break;
    case DigiviceBattlePhasePlayerHit:
        if(app->screen_frame < DIGIVICE_APP_HIT_FRAMES) break;
        if(digivice_battle_outcome(&app->battle) == DigiviceBattleWon) {
            digivice_battle_end(app, DigiviceBattleResultWin, "VIRUX DELETED! EXP UP");
        } else {
            digivice_battle_set_phase(app, DigiviceBattlePhaseFoeHit);
        }
        break;
    case DigiviceBattlePhaseFoeHit:
        if(app->screen_frame < DIGIVICE_APP_HIT_FRAMES) break;
        if(digivice_battle_outcome(&app->battle) == DigiviceBattleLost) {
            digivice_battle_end(app, DigiviceBattleResultLose, "SYSTEM CORRUPTED...");
        } else {
            digivice_battle_set_phase(app, DigiviceBattlePhaseChoose);
        }
        break;
    default:
        break;
    }
}

static void digivice_battle_draw_textbox(Canvas* canvas, DigiviceApp* app) {
    canvas_set_color(canvas, ColorWhite);
    canvas_draw_box(canvas, 0, 50, 128, 14);
    canvas_set_color(canvas, ColorBlack);
    canvas_draw_line(canvas, 0, 50, 127, 50);
    canvas_draw_line(canvas, 0, 50, 0, 53);
    canvas_draw_line(canvas, 127, 50, 127, 53);

    if(app->phase == DigiviceBattlePhaseChoose) {
        for(uint8_t i = 0; i < DigiviceBattleChoiceCount; i++) {
            int32_t x = 6 + i * 42;
            digivice_draw_text(canvas, x, 55, choice_labels[i]);
            if(i == app->choice) digivice_draw_brackets(canvas, x - 3, 53, x + 30, 62, 2);
        }
    } else if(app->phase == DigiviceBattlePhaseAim) {
        digivice_draw_meter(canvas, 14, 56, app->meter.zone_start, app->meter.cursor);
    } else if(app->message) {
        digivice_draw_text(canvas, 2, 52, ">");
        digivice_draw_text(canvas, 7, 52, app->message);
        if(app->phase == DigiviceBattlePhaseEnd && (app->frame % 6) < 3) {

        }
    }
}

void digivice_battle_draw(Canvas* canvas, DigiviceApp* app) {
    canvas_set_color(canvas, ColorBlack);
    for(int32_t y = 4; y < 50; y += 8) {
        for(int32_t x = 4; x < 128; x += 8)
            canvas_draw_dot(canvas, x, y);
    }

    uint32_t f = app->screen_frame;
    bool player_hit = app->phase == DigiviceBattlePhasePlayerHit && app->last_damage;
    bool foe_hit = app->phase == DigiviceBattlePhaseFoeHit;

    digivice_draw_ring(canvas, 96, 29, 17, 4);
    digivice_draw_ring(canvas, 96, 29, 10, 2);
    digivice_draw_ring(canvas, 32, 48, 18, 4);

    // The VIRUX lunges at the pet when it strikes.
    int32_t ex = 96;
    int32_t ey = 19;
    if(foe_hit && f < 6) {
        static const int8_t lunge[6] = {0, 12, 24, 30, 24, 12};
        ex -= lunge[f];
        ey += lunge[f] / 2;
    }
    if(!(player_hit && f > 1 && f < 8 && (f % 2))) digivice_draw_virux(canvas, ex, ey, app->frame);
    int32_t r = 13 + (int32_t)(app->frame % 4) / 2;
    digivice_draw_brackets(canvas, ex - r - 4, ey - r, ex + r + 4, ey + r, 3);

    int32_t px = 32;
    if(app->phase == DigiviceBattlePhasePlayerHit && f < 4) px += 4;
    DigivicePose pose =
        (app->phase == DigiviceBattlePhaseAim || app->phase == DigiviceBattlePhasePlayerHit) ?
            DigivicePoseAttack :
            DigivicePoseIdle;
    if(!(foe_hit && f > 5 && (f % 2))) {
        digivice_draw_form(canvas, (DigiviceForm)app->state.form, px, 40, app->frame, pose, false);
    }

    if(player_hit && f < 5) {
        // Beam from the pet's mouth to the VIRUX.
        int32_t bx = 44 + (int32_t)f * (ex - 56) / 5;
        int32_t by = 36 + (int32_t)f * (ey - 36) / 5;
        canvas_draw_line(canvas, 44, 36, bx, by);
        canvas_draw_line(canvas, 44, 37, bx, by + 1);
        canvas_draw_circle(canvas, bx, by, 3);
    }

    char number[8];
    if((player_hit || foe_hit) && f < DIGIVICE_APP_HIT_FRAMES) {
        snprintf(number, sizeof(number), "-%u", (unsigned)app->last_damage);
        int32_t nx = player_hit ? ex - 6 : 26;
        int32_t ny = (player_hit ? ey - 21 : 20) - (int32_t)f / 2;
        canvas_set_color(canvas, ColorWhite);
        canvas_draw_box(canvas, nx - 2, ny - 1, 18, 8);
        canvas_set_color(canvas, ColorBlack);
        digivice_draw_text(canvas, nx, ny, number);
    }

    digivice_draw_hp_box(canvas, 2, 2, "VIRUX", app->battle.foe_hp, app->battle.foe_hp_max);
    digivice_draw_hp_box(
        canvas,
        68,
        33,
        digivice_form_name((DigiviceForm)app->state.form),
        app->battle.player_hp,
        app->battle.player_hp_max);

    digivice_battle_draw_textbox(canvas, app);

    if((player_hit || foe_hit) && f < 4) digivice_draw_glitch(canvas, app->frame, 4);
}
```

```c
static void desktop_digivice_view_draw(Canvas* canvas, void* model) {
    DesktopDigiviceViewModel* m = model;
    if(m->state.evo_from != DigiviceFormNone) {

static bool desktop_digivice_view_input(InputEvent* event, void* context) {
    DesktopDigiviceView* digivice_view = context;
    // Only short Right is ours; every other key keeps its stock desktop meaning.
    if(event->key == InputKeyRight && event->type == InputTypeShort) {
        if(digivice_view->callback) {
            digivice_view->callback(
                DesktopAnimationEventInteractAnimation, digivice_view->context);
        }
        return true;
    }
    return false;
}

static void desktop_digivice_view_frame(void* context) {
    DesktopDigiviceView* digivice_view = context;
    bool evolution_done = false;
    with_view_model(
        digivice_view->view,
        DesktopDigiviceViewModel * m,
        {
            m->frame++;
            m->now = furi_hal_rtc_get_timestamp();
            if(m->state.evo_from != DigiviceFormNone) {
                // The cutscene is authored at 10 fps, so skip a frame at 5 fps.
                if(m->evo_frame < DIGIVICE_EVO_FRAMES) {
                    m->evo_frame += 2;
                } else {
                    evolution_done = true;
                }
            } else {
                m->evo_frame = 0;
            }
        },
        true);
    if(evolution_done) digivice_ack_evolution(digivice_view->digivice);
}

static void desktop_digivice_view_state_callback(const void* message, void* context) {
    DesktopDigiviceView* digivice_view = context;
    const DigiviceState* state = message;
    with_view_model(
        digivice_view->view, DesktopDigiviceViewModel * m, { m->state = *state; }, true);
}

static void desktop_digivice_view_storage_callback(const void* message, void* context) {
    DesktopDigiviceView* digivice_view = context;
    const StorageEvent* event = message;
    if(event->type != StorageEventTypeCardMount && event->type != StorageEventTypeCardUnmount &&
       event->type != StorageEventTypeCardMountError) {
        return;
    }
    bool sd_ok = event->type == StorageEventTypeCardMount;
    with_view_model(
        digivice_view->view, DesktopDigiviceViewModel * m, { m->sd_ok = sd_ok; }, true);
}

static void desktop_digivice_view_enter(void* context) {
    DesktopDigiviceView* digivice_view = context;
    furi_timer_start(digivice_view->frame_timer, furi_ms_to_ticks(DESKTOP_DIGIVICE_FRAME_MS));
}

static void desktop_digivice_view_exit(void* context) {
    DesktopDigiviceView* digivice_view = context;
    furi_timer_stop(digivice_view->frame_timer);
}

DesktopDigiviceView* desktop_digivice_view_alloc(void) {
    DesktopDigiviceView* digivice_view = malloc(sizeof(DesktopDigiviceView));
    digivice_view->view = view_alloc();
    view_allocate_model(
        digivice_view->view, ViewModelTypeLocking, sizeof(DesktopDigiviceViewModel));
    view_set_context(digivice_view->view, digivice_view);
    view_set_draw_callback(digivice_view->view, desktop_digivice_view_draw);
    view_set_input_callback(digivice_view->view, desktop_digivice_view_input);
    view_set_enter_callback(digivice_view->view, desktop_digivice_view_enter);
    view_set_exit_callback(digivice_view->view, desktop_digivice_view_exit);

    digivice_view->frame_timer =
        furi_timer_alloc(desktop_digivice_view_frame, FuriTimerTypePeriodic, digivice_view);

    digivice_view->digivice = furi_record_open(RECORD_DIGIVICE);
    digivice_view->storage = furi_record_open(RECORD_STORAGE);

    DigiviceState state;
    digivice_get_state(digivice_view->digivice, &state);
    bool sd_ok = storage_sd_status(digivice_view->storage) == FSE_OK;
    with_view_model(
        digivice_view->view,
        DesktopDigiviceViewModel * m,
        {
            m->state = state;
            m->sd_ok = sd_ok;
            m->now = furi_hal_rtc_get_timestamp();
        },
        false);

    digivice_view->state_subscription = furi_pubsub_subscribe(
        digivice_get_pubsub(digivice_view->digivice),
        desktop_digivice_view_state_callback,
        digivice_view);
    digivice_view->storage_subscription = furi_pubsub_subscribe(
        storage_get_pubsub(digivice_view->storage),
        desktop_digivice_view_storage_callback,
        digivice_view);

    return digivice_view;
}

void desktop_digivice_view_free(DesktopDigiviceView* digivice_view) {
    furi_assert(digivice_view);
    furi_pubsub_unsubscribe(
        storage_get_pubsub(digivice_view->storage), digivice_view->storage_subscription);
    furi_pubsub_unsubscribe(
        digivice_get_pubsub(digivice_view->digivice), digivice_view->state_subscription);
    furi_timer_free(digivice_view->frame_timer);
    furi_record_close(RECORD_STORAGE);
    furi_record_close(RECORD_DIGIVICE);
    view_free(digivice_view->view);
    free(digivice_view);
}

View* desktop_digivice_view_get_view(DesktopDigiviceView* digivice_view) {
    furi_assert(digivice_view);
    return digivice_view->view;
}

void desktop_digivice_view_set_callback(
    DesktopDigiviceView* digivice_view,
    DesktopMainViewCallback callback,
    void* context) {
    furi_assert(digivice_view);
    digivice_view->callback = callback;
    digivice_view->context = context;
}
```
